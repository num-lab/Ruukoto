# Implemented Decisions

These notes describe delivered decisions. Follow [root instructions](../../../AGENTS.md), the [layout](../README.md) and [maintain-notes](../../skills/maintain-notes/SKILL.md); the format validator checks structure.

Update paths, symbols, defaults and mechanisms in place with the corresponding code change. Replace stale facts rather than appending a change log. Reversing the decision or its rationale requires a new cross-linked note.

Archive a completed record only when its reasons no longer guide current work. Keep active guarantees, ownership constraints and plausible reintroduction conditions discoverable; [archiving](../../skills/maintain-notes/references/archiving.md) describes the distinction.
