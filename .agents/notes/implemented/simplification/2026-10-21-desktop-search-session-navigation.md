# Agent Note: 搜索结果直接打开普通会话

Status: implemented

## 问题

拥有者以实际界面截图要求删除搜索说明、「查看历史」栏和只读输入提示，并明确「不要新增一个查看历史，直接跳到对应的会话」。独立历史模式增加了找回会话之后继续交谈的步骤。

## 决定

搜索的名称项和正文项统一调用既有 openSession，关闭搜索后打开对应普通会话。沿用会话标签、最新投影、实时输出、向前分页、草稿、附件及正常输入，不再进入独立历史窗口或保证滚动到命中消息；结果片段继续帮助辨认会话。取消搜索恢复原焦点，选择结果后把焦点交给会话输入框。

本决定取代[Spotlight 搜索与历史定位](../feature/2026-10-21-desktop-spotlight-search.md)中的独立历史窗口、消息定位高亮及返回最新后才允许输入的部分；检索范围、存档标识、来源判定、读屏可访问性与性能要求继续有效。删除 renderer 窗口控制器、专属展示、提交守卫和无调用的 EventFlow 窗口方法；已经提供的后端 around／after 只读协议及其兼容测试保留，不为界面导航改动撤销共享协议。

## 备选方案

- 只隐藏历史栏和提示：改动更少，但仍隐藏着独立投影和提交限制，无法满足直接进入普通会话继续交谈的要求。
- 把命中附近页并入最新投影并保持定位：能保留原消息定位，但还需解决历史断层、300 条裁剪、实时事件与迟到最新页覆盖；超出本次明确的直接打开会话需求。

## 后果

会话打开复用既有路径，移除独立导航生命周期和只读状态。古老正文仍可被搜索并用于找回会话，进入后显示普通会话已有的消息范围，需要时按既有方式向上翻阅。工程证据与原生体验缺口记在[工单](../../../../.scratch/desktop-search/issues/01-spotlight-search.md)。
