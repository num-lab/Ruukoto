# Agent Note: 后台执行的生命周期独立于单次 bash 调用

Status: proposed

拥有者本轮仅要求「先记入笔记」，尚未授权实施。

## 问题

Agent 启动开发服务器、文件监听或测试依赖服务后，需要继续调用浏览器、检查日志或执行其他命令。当前工具 worker 在主 Shell 结束后回收整组，`nohup … &` 启动的 HTTP 服务只能在同一次 bash 内访问，后续工具调用连接拒绝。[真实会话诊断](../../../../.scratch/agent-browser/evidence/owner-session-diagnosis.md)已通过真实 worker 和隔离浏览器复现；补工具说明能解释限制，但不能提供这些执行能力。

当前 bash 接口只有 command / timeout 与最终结果，没有运行句柄、日志查询或继续执行接口。Driver 在任务自然结束时也停止 worker，因此仅放宽单次命令收尾，只能支持同一任务中的后续操作，不能跨拥有者消息保留开发服务。

## 方案

将命令调用完成与后台执行停止分开。最小修正是：主 Shell 正常返回后，其后台进程继续登记并活到当前任务结束，允许后续工具访问；任务自然结束仍回收这批执行。单次调用取消或超时停止该调用归属的执行，任务取消、失败、有效执行权限变化、worker 或应用后台停止继续触发对应执行单元的停止核实。会话默认模式变化仍按[完全访问决定](../../implemented/feature/2026-10-12-full-access-current-account.md)只影响后续任务。

跨轮开发服务拟提供显式受管执行句柄，支持查询状态、读取日志和停止，归属会话及实际启动授权。它需要独立于当前任务的 worker 生命周期；具体权限变化、工作目录占用、取消范围、正常任务结束后的归属转交和后台重启恢复尚需设计与独立审查。本篇先记录方向，不将这些待定规则视为已确认的实施契约，也不扩通用服务管理平台。

实现最小修正时仍需处理两个问题：后台继承 stdout/stderr 会使当前 `child.close` 等待管道关闭，调用完成应以主 Shell 退出及明确的输出处理为依据；后台执行停止要核实系统进程身份和归属，不能在主 Shell 消失后长期保存裸 PID/PGID，再向可能复用的数字发信号。后台日志与命令结果分别保留归属，进入模型的内容仍能从会话历史与产物重建。

停止未核实继续保留执行记录、目录占用和现场；结果未知的操作保持不重放。受限模式的执行仍使用现有平台边界，完全访问仍不承诺收回主动脱离管理的进程。实施落点是 agent 的工具 worker、宿主协议和路由、Driver 执行登记与收尾，以及对应模型说明、模块文档和回归测试；跨轮方案还涉及 Runtime / core 的持有与记录。

## 备选方案

- 保留每条命令结束即回收，并补清工具说明：执行范围短、清理直接，模型也能避开不支持的调用；但开发服务器、watch 与临时测试服务仍不能供后续工具访问，不能解决已复现的能力缺口。
- 只删除正常返回处的回收调用：改动最小，输出已重定向的后台服务可以继续运行；但没有解决继承输出管道造成的等待、进程身份复用与任务终态清理，不能作为完整修正。
- 由拥有者在外部终端持续运行服务：生命周期直观，是当前本地网页验收的可用办法；但每个预览都需要拥有者介入，不能替代 Agent 自主执行。`nohup`、双重 fork 或 `setsid` 也不作为规避停止归属的产品接口。

## 验收标准

- 真实 worker 启动合成 HTTP 服务，bash 返回后同一任务中的后续 HTTP 请求和 browser open 仍成功；任务正常结束后服务核实停止。
- 后台继承 stdout/stderr 的情况下，主 Shell 正常退出能使调用在有限时间内返回，后台输出按明确归属记录；命令退出码不被后台执行状态替代。
- 调用取消与超时、任务取消与失败、有效执行权限变化、worker 和应用后台停止覆盖对应归属执行；停止失败或查询失败保留未核实结论及占用，不自动重放动作。
- 进程身份不符或 PID/PGID 复用时不向无关进程发信号；macOS / Linux 各用真实进程验证普通后台服务和停止路径，离线替身不代替平台回收证据。
- 跨轮能力单独确认契约后，再验收启动句柄、日志与状态、跨消息访问、显式停止、会话隔离、权限变化、目录占用和后台重启恢复；当前最小修正不声称通过这些标准。

## 风险

后台服务会延长资源和端口占用，也可能在模型完成某条命令后继续修改工作区；必须让其归属、日志和停止结果可查。仅把清理延后到任务结束仍无法满足跨轮预览；跨轮转交又会影响工作目录占用与授权语义，不能用持久化一个 PID 代替完整设计。当前实现和工程验收保持原状态，本篇没有落地执行行为。
