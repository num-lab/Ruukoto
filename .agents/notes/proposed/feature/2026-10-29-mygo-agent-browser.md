# Agent Note: MyGo 右栏浏览器由 Coding 主 Agent 与拥有者接替操作

Status: proposed

## 问题

Coding Agent 的 browser 工具操作 Runtime 持有的 Chrome，MyGo 右栏则显示隔离 iframe；Agent 不能读取或操控拥有者眼前的同一页面。拥有者需要在桌面中完成本地前端验收，并能显式接管、交还页面。

## 方案

2026-10-29 的 grilling 访谈已确认下表；拥有者在完整方案交付后要求提交，方案据此定稿。本轮只提交方案，不实现功能。实施入口与验证方法见[工单](../../../../.scratch/mygo-agent-browser/issues/01-integrate-browser.md)。

| 决定 | 已确认的行为 |
| --- | --- |
| Q1、Q2 | 首要验收为打开本地开发页面、查看结构与截图、点击与输入、验证结果；不按网站用途限制，只开放 Coding 主 Agent |
| Q3、Q6 | 显式“接管”按钮撤回自动操作资格，当前任务在执行边界等待；“交还 Agent”让同一任务先重新观察再继续，不取消任务 |
| Q4、Q5 | 首版为 MyGo macOS 外壳，只开放完全访问；Electron、Personal、SubAgent、Plan、其他权限模式及后台来源不增加自动化能力 |
| Q7 | 每个主会话保留自己的页面；切会话、切右栏标签、收起右栏不销毁页面或打断自动化，也不抢当前界面；关闭浏览器或桌面后返回不可用 |
| Q8 | Agent 使用浏览器期间阻止人工点击、键入与滚动；接管后开放，空闲时可直接操作；不依赖鼠标活动检测 |
| Q9 | 网站登录态共享，页面现场按会话独立；不导入系统浏览器资料；保留站点允许持久化的登录信息，不在重开桌面时恢复旧页 |
| Q10 | MyGo 发起的任务固定操作右栏；TUI 原 Chrome 工具保持；桌面缺席或断线不自动改用 Chrome |

### 原生页面与技术前置

主路线使用 MyGo v0.5.5 的 WindowOptions.Content：一个前端 WebView 保留完整 React UI，各主会话另持有一个浏览器 WebView。React 只报告网页占位矩形、可见性和遮挡状态，原生 Content 用绝对布局展示当前页；不把三栏改写为原生组件，不扩通用电脑控制。独立页面解决 iframe 跨源不可读、切会话卸载和截图混入聊天的问题。已有 MyGo API 足以表达这条路线，但不能证明隐藏页面持续渲染或截图新鲜度。

实施第一步必须用真实 MyGo 应用探针证明：两个独立会话页保留现场；隐藏、收栏和弹层遮挡时自动化仍能执行并取得含最新计数的截图；窗口缩放、右栏动画、菜单与模态框、焦点和中文输入可用；网页收不到桌面事件、不能调用宿主方法。任一必需项不成立，先退回方案者修订原生接法，不降低 Q7、不无声切换外部窗口，也不先实现整套后台协议。探针后可在相同确认范围内调整原生适配；新增依赖、fork MyGo 或提高 macOS 下限须说明必要性并复审。

MyGo 源码依据为固定版本的 [WebView](https://github.com/egoist/mygo/blob/v0.5.5/webview.go)、[嵌入示例](https://github.com/egoist/mygo/blob/v0.5.5/examples/embed-webview/main.go)、[IPC](https://github.com/egoist/mygo/blob/v0.5.5/ipc.go) 和 [Cookie](https://github.com/egoist/mygo/blob/v0.5.5/cookies.go)。当前所有 WebView 使用应用共享的持久 WebKit store，不承诺按工作区、会话或产品隔离网站登录态；PA 的配对凭据继续由现有钥匙串与宿主持有，不进入网页。原生隐藏截图、合成 DOM 操作与 React 表单兼容性均尚未实测。

### 宿主隔离

迁入 Content 后，可信调用者必须同时匹配前端 Page 对象、宿主窗口和精确前端 URL；只核实 URL 与窗口不足以区分另一个独立 WebView。桌面更新从 Emit(window) 改为 EmitPage(frontend.Page())，不能把聊天、审批或任务事件广播给网页。浏览器不安装应用 preload、不授予 TrustedOrigins 或宿主 IPC；导航不能进入应用协议或桌面前端。设备、媒体、下载和弹窗继续拒绝。

原生浏览器覆盖在前端 WebView 上，CSS z-index 无法把 React 弹层提升到它上方。前端打开重叠菜单或模态框时撤下浏览器展示并保留实例；关闭后恢复。矩形按可信前端报告核实坐标、边界与当前会话，覆盖 ResizeObserver、200ms 右栏动画、窗口变化与 Code/Personal 切换。接管按钮属于可信前端，始终可达。截图只来自目标浏览器 WebView，不从整个聊天窗口裁图。

### 任务目标、工具与记录

MyGo 提交任务时由已认证、已登记浏览器能力的桌面连接固定目标归属，保存足以重建工具选择的来源事实。目标包含控制实例、桌面连接代次与主会话，不能由模型参数或网页指定。提交幂等核实、排队、继续和引导均不得把已有任务静默换目标；运行中的 TUI 任务不会因打开 MyGo 而改用右栏。重连、新窗口或另一连接不能继承旧页面句柄或抢占原绑定，需重新绑定并观察；未决动作不重发。

新增专用宿主工具 desktop_browser；仅 MyGo 来源的合格任务装配它，并隐藏旧 browser，TUI 与其他既有调用方继续使用旧工具。复用 HostToolFamily、工具操作账本、权限版本复核与 ArtifactStore，不让旧 Chrome manager 承担 WKWebView 生命周期，不新增 MCP 服务、配置选择器或通用双向 RPC 框架。

首版动作限定为状态、打开 URL、DOM 快照、视口截图、点击、填写、选择、勾选、滚动、有界等待和关闭。每会话一个页面，不增加多标签管理。DOM 操作是宿主固定脚本，不向模型开放 eval、任意脚本、Cookie、原生句柄、路径或连接端点；常规表单必须实测，拖拽、画布操作、富文本键盘操作、上传下载、全页截图、console 与 network 不在首版。页面内容和脚本结果按不可信数据处理。

MyGo EvalContext 会先按表达式尝试、遇特定语法错误再按函数体执行；固定变更脚本使用含显式 return 的函数体，使第一次尝试在编译阶段失败而不执行动作。原生探针用“产生一次副作用后抛 SyntaxError”的计数页验证不重复执行，不另加宿主自动重试。

模型导航只接受现有无凭据 HTTP(S) 地址范围；已有 file 入口保持拥有者主动预览及其文档能力根，不把任意 file URL 或本地目录授权加入模型工具。Agent 若观察拥有者已打开的本地文档，只能观察其当前页面，不因此取得新的文件打开接口。本机文档 handle 改由原生会话页面持有，切会话、隐藏、弹层遮挡和 React 占位卸载都不 release；导航、刷新、关页或宿主退出时才沿既有回收机制释放。模型结果使用拥有者原始文档地址，不暴露临时 loopback 地址及能力令牌。present(url) 继续按四模式登记展示；在 MyGo 中交给同一原生页面，展示与自动化资格分开，导航使旧元素引用失效。旧 live 结果与重放的区分保持，接管中暂缓模型发起的新导航并在交还后重新核实。

页面结构、实际 URL、标题和动作结果进入工具记录；截图先校验并保存不可变图片产物，再交给模型。未成功记录的观察不能授权下一次元素动作。元素引用绑定主会话、页面代次与已返回模型的快照；导航、手工接管、页面销毁和重绑均使引用失效。交还后必须取得新的快照；暂停前已准备好的点击不得原样延迟执行。页面摘要若在工具外进入模型输入，也必须有可重建的持久事实。

### 控制通路与失败

控制面增加窄的、已认证连接绑定的浏览器命令及应答；普通持久事件仍仅承担历史和投影，不传可重放动作。链路为 Runtime 宿主工具 → Control 连接 → DesktopHost/CodeController → MyGo 私有 JSONL → 原生页面。命令 ID、连接代次、主会话、页面代次与在途状态由宿主管理；结果不能跨连接或跨页接受。单页串行且有期限，原生回调迟到不得重新生效。

控制面现有单帧上限为 1MiB，MyGo JSONL 为 16MiB，图片总预算为 8MiB，不能把图片 base64 塞进一帧控制面应答。截图经桌面 Node 拆成有界分块（例如每块 256KiB 原始字节），携带命令绑定、块序、总字节数和完整摘要，由后台在该连接与命令内重组、校验格式/大小/摘要后导入 ArtifactStore；不提高全局帧上限，不借用拥有者附件授权语义，不把临时传输引用放进模型正文。快照文本同样遵守帧预算，超限明确标记并保存为可补读产物，不静默截断元素集合。断线、取消或期限到达回收未完整传输的分块，不把取图失败变成动作重试。

只有可核实未发出或明确被拒绝的动作才是已知未执行；只读失败无写入效果；变更命令一旦发出而无法证明未执行，应答丢失、超时、取消或进程退出均标为效果未知，不依赖可能丢失的“已开始”确认，不重放。断线立即撤销该连接的自动化资格，解除等待并向原调用返回有类型的不可用或未知结果；重连不自动恢复资格、交还控制或重发。后台重启沿原任务中断恢复；页面、桌面、后台关闭与权限变化都必须完成在途等待，不新增持久动作队列。

### 接管顺序

点击接管先由原生宿主关闭自动化闸门、改变页面代次，再通知后台并开放人工输入；后台通知迟到也不能放行新网页动作。Agent 持有页面时，前端地址栏导航、后退/前进、刷新和其他拥有者打开入口也受同一闸门约束，须先接管；接管与关闭按钮始终可用。已发出的网页动作、模型请求和其他工具只收尾到现有边界，不承诺撤回外部效果、冻结网页脚本、已有进程或独立 SubAgent。网页动作发出前再次核实本地控制归属；浏览器工具按 sequential 执行，阻止已准备的工具批次越过接管门。

Driver 在模型发送、工具调用与任务收尾边界加入仅此浏览器接管的可取消等待，任务保持 running，投影显示“等待交还”；不借审批、ask_user、队列暂停或新增 paused 终态。取消先解除等待再等待 SDK abort，避免互等；断线、关闭、权限失效同样解除等待。交还按钮是新的可信拥有者动作，只有它能交还，模型不能调用 resume。该新通路取代旧 browser 必须新消息/新任务才能 resume 的规则，旧 Chrome 工具的暂停规则保持。

交还后宿主先取得新 DOM 观察，把原文、页面代次和可信交还事实写入会话 marker，再由 ContextAssembly 将这份观察作为明确标源的参考块交给下一模型调用，不伪造无 tool_call 的工具结果或用户消息。沿既有 reportContext 的记录/发送前核实方式验证 marker 实际落盘，失败不继续；更新 agent-context 文档与 CONTEXT 的参考块说明。若接管发生在最终回答期间，Driver 的 finishTurn 必须返回 continue，强制同一任务再发一次包含该观察的模型请求，不能只等待后沿旧回答 completed。prepareNextTurnWithContext、prepareRequest 和发送前兜底同时复核控制代次；暂停前已准备的调用或请求不能拿旧上下文直接发送。若页面关闭或断线使新观察不可得，记录不可用事实让模型报告限制，不伪造已观察。每次交还只触发一次续轮，后续再接管使用新代次。

是否完成重新判断，绑定该次请求实际携带的观察 ID，并以其取得有效模型回答为准；交还、发送或更早请求的迟到回答不能清除“必须重新判断”标记。取消和错误仍优先收尾，不为满足续轮强行重试模型请求。

## 备选方案

- 保留 iframe，由宿主定向执行脚本：对 Electron 的改动较小，能保留现有隔离；MyGo 公共 API 没有子 frame 执行能力，且隐藏 iframe 无独立截图，不能满足已确认范围。
- 现有 Page 窗口加窄的 Darwin WKWebView 适配：保留前端窗口与 IPC，浏览器不必装 MyGo runtime；但需自行持有布局、导航、权限、截图和回调收尾，先探针 Content 路线，必要时在同一目标下复审比较实际改动量。
- 复用独立 Chrome，通过右栏展示截图或另开窗口：复用现有自动化与登录管理；截图转发还需人工输入、焦点和显示链，另开窗口不满足操控同一右栏页面，故不作为自动降级。
- 同一 browser 名称下泛化 Chrome/WKWebView manager：模型动作名统一；但两者进程、页面与暂停规则不同，扩大旧 manager 改动，采用互斥装配的桌面专属工具。

## 验收标准

验收逐项见[工单](../../../../.scratch/mygo-agent-browser/issues/01-integrate-browser.md#验收与证据)。至少包括真实 MyGo 原生探针、本地 React 表单闭环、双会话隐藏执行与新鲜截图、接管/交还与旧引用拒绝、在途取消和断线不重发、网页 IPC 与桌面事件隔离、TUI/Electron/Personal 回归，以及真实视觉模型独立外验；离线或模拟成功不能代替原生和真实模型证据。

## 风险

隐藏 WKWebView 的渲染、截图与焦点是首要技术缺口，探针失败即停止扩大实施。DOM 合成输入与浏览器真实键鼠有区别，常规 React 表单仍须实测；业务需要拖拽、画布或受信输入时重新讨论能力范围。每个打开的会话页都占内存，收栏不回收，拥有者可主动关闭；不加未确认的自动淘汰策略。共享 WebKit 登录数据会使一个会话的登录/退出影响其他网页。接管约束边界后的新工作，不能撤销先前发送的外部动作。
