# 01 — 两个产品独立安装和启动

**What to build:** 以两个产品入口启动独立实例，配置、数据、凭据和停止操作互不影响；在迁移期兼容现有角色与旧数据。

**Blocked by:** 无，可立即开始

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 两个产品可以分别构建、安装和升级；升级或停止一端不要求另一端同时升级或停止。
- [ ] Coding Agent 不启动消息平台连接或个人调度；Personal Agent 可独立进入原有拥有者主会话。
- [ ] 同机并存时配置、数据锁和控制面不会串用；新产品不会误用开发本项目的隔离实例。
- [ ] 采用兼容扩展接入产品类型，保留旧记录的可读性，不在本单全局重命名角色或存储字段。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
