# 03 — 验证开发机执行权限的技术边界

**What to build:** 用可复跑的最小原型验证 macOS 可用的受限执行方式，并复核 Linux 现有路径，为产品接入提供实际证据。

**Blocked by:** 无，可立即开始

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 实际演示授权工作目录内读取、修改和运行检查，同时拒绝未授权文件、网络与控制面授权材料访问。
- [ ] 验证子进程不能绕过边界；停止操作能回收实际执行进程，不能只终止界面。
- [ ] 明确受限模式与完全访问模式各自的系统身份、控制面保护和前置条件；完全访问不能伪造拥有者身份。
- [ ] 记录验证环境、可行方式、限制和复跑步骤；没有可行方式时如实记录阻塞，不能把 local 无隔离路径当作验证通过。
- [ ] 复用现有 Linux 后端开展检查，避免重复建设已经交付的容器和执行账户机制。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
