# 04 — 在开发机完成受限和完全访问任务

**What to build:** 把已验证的执行方式接入实际开发任务，macOS/Linux 均可完成一次代码修改和检查，并由拥有者明确选择权限模式。

**Blocked by:** [03 — 验证开发机执行权限的技术边界](03-execution-boundary-proof.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 真实工具执行使用已验证的系统边界，能完成授权目录内的代码修改与检查。
- [ ] 越界操作遵循审批规则，子进程与实际文件、网络访问也受约束，不能仅检查工具参数。
- [ ] 完全访问由拥有者显式选择，使用已定义的执行身份，不获得控制面授权材料。
- [ ] 受限后端缺失或失效时在执行前拒绝，不静默回退到普通账户执行；停止和异常中断沿用未知效果规则。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
