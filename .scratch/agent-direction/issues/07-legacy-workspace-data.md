# 07 — 把旧开发会话和资料映射到工作区

**What to build:** 升级旧开发数据后，拥有者能按工作区找到原会话、历史和产物，记忆及资料权限保持原有边界。

**Blocked by:** [05 — 按工作区创建和切换开发会话](05-workspace-sessions.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 同一旧项目包含不同目录时可形成可核查的工作区映射；目录失效或归属有歧义时明确列出，不静默猜测。
- [ ] 历史、产物、记忆来源、指令及工具配置仍可定位，保留旧标识作为必要的兼容来源。
- [ ] 跨项目资料授权映射不隐式扩大；撤销授权后的查询与上下文注入仍按来源校验。
- [ ] 迁移重复执行不重复创建，失败可恢复；源记录保留，不要求删除旧存储字段。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
