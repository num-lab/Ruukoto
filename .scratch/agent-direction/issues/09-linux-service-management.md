# 09 — 通过 IM 检查并管理 Linux 服务

**What to build:** Personal Agent 用专用账户检查指定测试服务，经 IM 批准实际执行需要授权的管理操作，并向原入口汇报。

**Blocked by:** [08 — 在绑定拥有者的 IM 私聊完成审批](08-im-approvals.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 完成服务状态或日志检查、提出指定管理操作、IM 审批、真实执行和结果返回的完整链路。
- [ ] 提供真实可验证的主机执行及必要提权边界，不能仅向 main 开放 bash 就宣称具备服务器管理能力。
- [ ] 授权固定操作和目标，控制面、后台凭据和其他任务权限仍受保护，越界及权限不足明确失败。
- [ ] 开发机器离线不影响此服务器侧流程；执行中断或结果未知不自动重发管理操作。
- [ ] Linux 验证使用可控测试服务，保留可复跑证据；模拟平台测试与真实服务操作验证分别说明。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
