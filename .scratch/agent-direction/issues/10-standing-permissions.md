# 10 — 保存、使用和撤销限定的长期授权

**What to build:** 拥有者为具体操作和目标授予持续权限，后续任务可在有效范围内执行，撤销后恢复审批。

**Blocked by:** [09 — 通过 IM 检查并管理 Linux 服务](09-linux-service-management.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 拥有者可以创建、查看和撤销一条明确的操作与目标授权，例如重启指定测试服务。
- [ ] 新任务命中有效范围可执行，换目标或操作必须重新审批；撤销后下一次执行不再放行。
- [ ] 执行前重新核实授权版本与范围，模型、子任务消息和普通平台文本不能自行创建或扩大授权。
- [ ] 单次批准不因长期授权机制而跨任务复用；不默认开放任意 root 操作，不放宽既有特殊审批规则。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
