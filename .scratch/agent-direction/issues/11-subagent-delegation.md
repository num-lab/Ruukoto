# 11 — 主 Agent 委派通用 SubAgent 并收到结果

**What to build:** 在已有开发会话和 main 中走通通用委派：登记工作委托，创建独立 SubAgent，执行有界任务、返回结果并保持空闲。

**Blocked by:** 无，可立即开始

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 主 Agent 可创建 SubAgent 并执行一个受控读取或分析任务，拥有者可查工作委托、子任务状态和结果。
- [ ] SubAgent 完成后保留身份与上下文、进入空闲，不自动关闭；主会话在等待结果期间仍能处理新消息。
- [ ] 工作委托与一次执行任务明确区分，跨主 Agent 对话轮次仍能关联原工作；重复委派不会重复创建同一次执行。
- [ ] 工具和资料由宿主限定；SubAgent 不能再创建下级、直接向拥有者发送或取得拥有者控制面身份。
- [ ] 新增通用身份与旧固定角色兼容共存，复用已有任务、历史、结果和幂等机制；本单不删除旧 coding 调用路径。
- [ ] 现有 main 的分析委派接入通用只读路径，保留旧修改委派兼容，避免最后清理时才补分析职责迁移。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
