# 13 — 让同项工作的 SubAgent 相互通信

**What to build:** 同项工作中的多个 SubAgent 交换有来源的消息并协作，复用到新工作后旧协作者失去通信资格。

**Blocked by:** [12 — 继续委派、跨工作复用并显式关闭 SubAgent](12-subagent-reuse-close.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 两个 SubAgent 可在同项工作内发送和接收消息，消息及来源可追溯，上级也能向其发送补充。
- [ ] 跨主 Agent、用户会话、工作区或当前工作范围的消息被拒绝，消息本身不扩大权限。
- [ ] 接收者被复用于新工作后，旧成员及迟到旧消息不能进入新的工作上下文。
- [ ] 重复投递不重复形成同一条逻辑消息；关闭后的投递有明确结果，不把关闭视为重新创建 Agent 的理由。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
