# 17 — 汇总并验证并行改动，保留冲突成果

**What to build:** 主 Agent 将子任务改动汇入所属工作区、处理冲突并运行检查，失败时仍可找回每份成果。

**Blocked by:** [12 — 继续委派、跨工作复用并显式关闭 SubAgent](12-subagent-reuse-close.md)；[14 — 取消整项工作而不影响其他委托](14-cancel-work.md)；[16 — SubAgent 在独立 worktree 中并行修改](16-parallel-worktrees.md)

依据：[已确认规格](../spec.md) 与 [ADR 0017](../../../docs/adr/0017-two-agent-products.md)。

## 验收标准

- [ ] 从多个执行副本收集修改，按明确来源汇入主工作区并运行相关检查，结果关联原工作委托。
- [ ] 冲突或检查失败时保留主工作区原有改动与各子任务成果，向拥有者说明待处理内容，不强制覆盖。
- [ ] 取消工作或关闭 SubAgent 不会删除尚未汇总的修改；汇总与关闭竞争时保持可恢复记录。
- [ ] 汇总前核实原工作区和副本状态，Agent 身份复用不导致把旧工作改动合入新工作。
- [ ] 现有 main 的代码修改委派通过通用 SubAgent 产生、汇总并验证改动，普通分析和修改职责均有替代路径，旧固定入口仅保留迁移期兼容。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
