## 验收标准

- [ ] 先验收本地编码和测试，再验收 IM 服务器管理，最后验收长任务期间持续响应、协作、复用和显式关闭。
- [ ] 一端关闭或失联时另一端完成本地任务；分别安装、升级与停止，配置和数据不串用。
- [ ] 实际验证 macOS/Linux 执行权限、IM 审批和限定长期授权，明确模拟平台验证与真实部署验证的覆盖差别。
- [ ] 联合演练旧实例迁移、重启、取消、冲突与回退，检查历史、产物、授权范围和未知效果处理；整项取消后的迟到同级消息不能重启工作。
- [ ] 只补联合路径中尚未覆盖的检查，汇总已有各票证据；更新发布说明及运行图解，不把后续共享、邮件或正式外挂列为首期已交付。
- [ ] 完成相关端到端检查、类型检查及仓库要求的验证；同步本次行为涉及的运行说明和图解，验证记录区分模拟结果与真实环境结果。
