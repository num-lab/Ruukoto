# 工作流脚本隔离实验与执行入口

Status: resolved

## 目标与边界

落实[规格 A3](../spec.md)的脚本执行前提，依据[实施计划第二节](../implementation-plan.md#二受限脚本与步骤结果)和[候选资料](../script-runtime-research.md)验证 QuickJS/WASM 与独立进程。不运行真实模型，不在实验通过前把候选宣布为已选定。

## 实施与交付

1. 在隔离副本或临时目录建立可复现的假 Agent 实验，核实同步 WASM、Promise 桥、模块加载与资源回收。
2. 验证纯计算、微任务与长内建操作中止、解释器内存/栈限制、IPC 背压、超大输入输出与取消后迟到消息；证明脚本不能取得 Node/文件/网络/凭据能力。
3. 在 macOS/Linux × Node 22.19/24.15 上运行实验，Linux 使用 `ssh tx`；保存版本、命令、故意失败用例与原始结果。
4. 通过后给出最小固定编排入口与专用协议，复用现有进程身份和停止核实，明确解释器限制与整个进程内存保证的差别。新增依赖只放实际使用的包，锁定 lockfile，核实打包后的 WASM 路径。

涉及 packages/agent/src/execution、tool-worker 相邻的专用编排入口、构建脚本与依赖声明。编排入口不直接导入 runtime；宿主调用通过受控消息与注入回调，遵守现有依赖方向。

## 实施结果

已选定 QuickJS core + release-sync 0.32.0，依赖仅声明在 agent 包，根锁文件固定版本。`packages/agent/src/script-worker/` 持有固定进程入口、专用有界协议、JSON Promise 桥和宿主回调；不导入 runtime，不按来源完全访问扩大脚本能力。`npm run build:script` 自包含打包 JS，并从实际依赖复制同目录 WASM，`npm run build` 已接入；说明同步 README、开发说明、execution、架构地图和 pre-push-checks。[决定](../../../.agents/notes/implemented/architecture/2026-10-13-workflow-script-isolation.md)持有中止/回收与限额取舍。

来源要求与实际内容对照、版本/命令/原始结果见[隔离证据](../isolation-evidence/README.md)。纯计算、微任务和长内建均由真实独立进程回收；QuickJS 堆/栈、WASM 线性内存和 V8 old space 分开限定，不承诺进程 RSS 配额。正常结果还须正常退出和原进程组核实，失败与取消保留身份、结果和未核实结论。

## 验收证据

- 平台：原型 macOS/Linux × Node 22.19.0/24.15.0 各 35/35 后才选型；最终自包含资产四格各 37/37、零跳过，含独立审查新增的同步启动异常和合法 32 并发加微任务回归。
- 工程：`npm run build`、`npm run check:static` 通过；104/100/101 首次联合 70/70，最终 104 源码 37/37，原始日志分别保存。最终 build 和静态门禁日志为 `isolation-evidence/build-accepted.log`、`static-accepted.log`。
- 独立审查：上下文 `isolation_seams` 亲读有效要求、实际源码/构建/文档，并执行最窄检查；发现并解除 JSON 原型变形、伪造 primitive 类型、零请求 idle、终态异常退出、同步启动身份及 32 请求队列计数问题。通过撤去 primitive 类型防护与队列计数修复，亲自证明回归断言会红；最终核对四格 37/37 日志与三项资产 SHA-256，无未解决实现或平台阻断。根实施者的静态门禁通过与此独立结论共同满足工程验收。
- 产品体验不适用：本单交付执行库层，无产品发起或 UI。未运行真实模型或 IM，也未执行全量 `npm run check`；后续整体工作流和实际步骤的验收仍由 03–07 持有。
