# 精简测试并恢复 CI 的完整反馈

Status: ready-for-human

## 目标与边界

拥有者先要求“尽可能地精简测试，只留下真正必要的，先只做评估”，随后要求制定并提交计划，2026-10-24 要求接手本工单，现进入实施与验收；不推送或部署。测试策略按[决定](../../../.agents/notes/implemented/testing/2026-10-24-test-suite-reduction.md)执行，既有产品行为、数据兼容和安全边界保持。

成功标准是保留能解释其独有作用的测试，删除退役产品的运行验收与重复覆盖，减少必要测试的重复启动成本，并使现有 macOS/Linux × Node 22.19/24.15 四格在 45 分钟内完整通过。每格总 job 不超过 30 分钟是优化目标，尚无实测支持，不作为可以削弱行为覆盖的理由。51 条是首批候选，不是删除配额或工作终点。

本批不增加依赖或通用测试框架，不改变产品权限、协议、数据格式与执行预算，不通过 skip、自动重试、提高 45 分钟限制或减少平台矩阵取得通过。首次对比保持现有文件并行 2 和 macOS 独占清单。生产缺陷若在诊断中确认，先保存反例，按局部修复另立关联工单；仅减少测试的变更不夹带产品重构。

## 方案

### 阶段一：固定基线，定位卡住与既有失败

1. 实施开始记录实际 HEAD、工作区差异、Node/OS、系统前提、并发和离线开关。评估检出为 `902eeac5`，实施起点为 `28c033f7`，最近读取的远端 run 是 `39732364834`、提交 `419c8384`，三者不能混作同一版本。
2. 保存旧 CI 的失败清单与适用提交，优先核对 `15-tui-pty`、`118-workflow-entries`、`122-workflow-code-acceptance`、`125-agent-wait`。逐项区分产品缺陷、夹具竞态、资源竞争和已过期断言；`122` 的 `write_result_missing` 必须查清，不能以减输入后通过代替归因。
3. Linux 用拥有者指定的 `ssh oracle-4c24g` 隔离检出做有界诊断，核实所用 Node 和系统前提。先观测测试文件开始/结束、PID、存活进程树及未关闭句柄，再收窄到实际阻塞文件或并发组合。第 841 条之后无输出只能作为观测窗口，不能据此指定 `33-config-tui` 为根因。采用临时诊断输出或现有 Node 能力；诊断到期非零退出并保存现场，不杀其他检出或用户进程。
4. 确认根因后仅修复受影响夹具的释放、停止或阶段同步；需要产品修改时按第一段另行记录。保留可复现反例，并证明同样扰动下修复有效。若需要长期的测试进程期限，先确认 Node 两版本支持和正常最慢用例预算，超时必须报失败且回收本次进程，不能把强退当成功。
5. 建立可比较的完整基线：同一机器、Node、系统前提、并发、离线开关与依赖，单独记录 setup、build/static、test:app、foundation 和总墙钟。旧 45 分钟超时是截断样本，不用于计算完整加速比例；已有完整日志只作排序线索。若完整基线仍卡住，先完成归因，不反复等待 45 分钟；确认无依赖的候选审查可以继续。

完成条件：每项旧失败有当前适用性与归属；Linux 无输出现象有可复现机制或明确的待补证据，不以最后输出文件冒充根因；后续计时有固定环境和比较对象。

### 阶段四：审查余下集合并收敛

按当前完整发现清单继续审查所有测试文件，以模块汇总“保留、删除、合并、降层及理由”，不维护一份重复全部断言的永久清单。优先 `83-subagent-worktrees`、`workspace-snapshot-runtime-boundaries`、`desktop-session-settings`、`14-tui-app`、`15-tui-pty` 等高成本文件，再清理低成本但仅锁定实现写法、旧文案或相同映射的断言。对 `verification/foundation` 只按现行 SDK 接入契约判断去留，不把其约 3 秒耗时当作性能主战场。

保留每种独有业务不变量的最窄用例及必要跨层接线；安全负例和真实平台边界不按比例削减。相同业务在不同存储、传输或执行边界上的测试不自动视为重复。源码正则若是唯一的安全接线证据，先提供更直接的行为证明再考虑删除。

同一轮审查中已确认的冗余全部处理后，若只剩必要覆盖却仍不能满足时限，提交实测和最慢保留集合，单独提出轻重测试调度方案。push/PR 去重、静态单跑、分片和改变并发不混入首次裁剪，以免隐藏收益或重现 worker 竞争。

完成条件：全部测试文件均已归入模块审查结果，所有删除候选有结论，保留的慢文件能解释真实边界和代表性规模；不因达到某个删除数或首次低于 45 分钟就跳过剩余明显重复项。
