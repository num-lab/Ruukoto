# Coding Agent 消息重排与引导规格

## 目标与确认依据

让拥有者在 Code 主会话工作期间整理待发消息，并向当前任务补充或纠正要求。本文是本功能的产品要求；实现取舍见[决策草案](../../.agents/notes/proposed/feature/2026-10-28-coding-message-control.md)，实施与审查见[工单](issues/01-queue-and-guidance.md)。

拥有者在 2026-10-28 的 grill-me 访谈中确认：Q1 将“插队”定义为调整正在排队的消息顺序；Q2 同时覆盖桌面 Code 聊天与 TUI；Q3、Q4、Q6 采用推荐；Q5、Q10 明确未赶上的引导作为普通用户消息放到队首、任务结束后立即发送；最后明确确认 Q7–Q9。以下为合并后的有效约定，不以早期推荐覆盖后续修改。

## 范围

首版只作用于普通 Code 会话中拥有者直接对话的主 Agent。个人 Agent、SubAgent 会话、工作流步骤与活动 Code 定时运行不开放这些入口。普通主会话中的内部汇总由宿主管理，不提供消息重排或转引导操作；普通用户输入、继续输入及拥有者问题回答须保留各自来源语义，不能把后两者仅复制成一段正文。

不新增消息编辑、批量操作、拖拽、优先级设置或模型可调用的重排／引导工具。

数据库版本切换沿用仓库已确认的[不保留旧格式兼容决定](../../.agents/notes/implemented/simplification/2026-10-24-code-instance-mcp.md)：新 schema 使用新数据目录，不能原地继续旧实例会话；旧 SQLite、JSONL、产物与凭据原地保留，不迁移、不清空。本功能不自行翻转该决定或增加迁移器。切换前仍须在原版本停止并核实旧任务及受管进程，不能以新档案替代停止证明。

## 行为要求

| 编号 | 约定 |
| --- | --- |
| R1 | 普通 Enter 仍提交普通消息；当前任务执行期间默认排队，包括当前任务等待后台结果时。新普通消息追加队尾，不因普通输入自动中断当前任务。 |
| R2 | 可任意调整仍待执行的拥有者消息顺序，不中断当前任务，不改变原正文、附件、请求身份、模型、权限、继续来源或回答来源。 |
| R3 | 新输入可显式引导当前任务，已排队消息也可转为引导。转换后不再同时作为独立任务执行；同文消息仍有不同身份。 |
| R4 | 引导在下一安全边界进入当前任务：不强行结束模型当前输出或已开始的工具；当前模型轮及其工具批次结束后，下一次模型请求按接纳顺序一起读取全部待处理引导。 |
| R5 | 接纳引导后，使当前任务尚未消费的审批失效，并解除 SubAgent／工作流／后台进程结果等待，让主 Agent 读取引导；不批准旧操作，不取消后台工作，不撤回已执行操作。旧工具批次随后才到达的审批同样不能挡住或抢先消费。 |
| R6 | 目标任务未赶上接收的引导作为普通用户消息进入队首，完成后优先执行；多条回退按接纳顺序组成一个队首批次，不能逆序，也不能被随后回退的消息插到前面。 |
| R7 | “立即”指队列允许调度且执行资源可用时启动下一项；回退不解除队列暂停，不越过停止、重启恢复、目录占用或停止未核实规则，也不自动重放已进入目标任务的输入或工具。 |
| R8 | 引导沿目标任务当前固定的模型与权限运行，文字不能切换模式、扩大路径授权或改变来源身份；回退独立执行时保留原提交选择。附件与图片和普通消息保持相同能力、归属与校验。 |
| R9 | 消息先由后台持久接纳，再应答和广播；重连、丢答、重复请求、模型收尾及后台重启不使同一输入丢失、重复成消息或再次独立执行。不能用正文匹配身份，也不能把 SDK 入队说成模型已读。 |

## 交互要求

有待发消息时，在输入框上方显示紧凑队列。桌面每条提供上移、下移、引导；上移／下移支持键盘，首尾对应动作禁用，移动后保持焦点并提供辅助技术可读的位置反馈。TUI 的 `/queue` 用现有选择界面选消息和动作，不要求手输任务 ID；`/steer 正文` 明确引导新输入，不占用已有换行或模式快捷键。

待执行输入只在排队区展示，实际开始执行或归入当前任务历史后，才在聊天流显示同一条用户消息，不重复气泡。引导没赶上时不额外标“未送达”，按普通队首消息展示。真实请求失败、应答丢失或队列冲突仍沿现有可行动错误反馈处理；这不属于为正常回退新增状态标签。

聊天气泡按稳定源输入身份区分，执行目标只用于任务分组；同一目标中的原要求、同文多条引导和问题回答分别保留，答案卡只替换对应的那条输入。聊天位置依据实际执行开始或历史接入证据恢复，不沿用排队创建时间；例如先创建 B、C 再重排为 C、B，上一任务最终回答后应依次显示 C 的输入／回答、B 的输入，不插回早先位置。

暂停的队列可以整理顺序，整理不自动恢复。另一客户端已改变队列或目标消息已经开始时，刷新实际队列并说明本次未应用，不自动覆盖新顺序。内部汇总不参与普通用户消息重排；普通重排只置换用户输入原有位置，回退引导按 R6 进入实际队首。

## 产品验收

桌面与真实 TUI 均须由拥有者确认：默认发送与显式引导容易区分；能调整至少三条消息为任意顺序；可将既有消息用于引导；队列与聊天流没有重复或错位；能看清正常回退后的实际队首，且不多出“未送达”标签。桌面还覆盖键盘、长消息、附件、明暗与窄窗口；TUI 覆盖选择退出、长消息摘要及已有快捷键。

产品验收在实现后执行；本轮只确认行为与方案，不宣称真实客户端或真实模型验收通过。
