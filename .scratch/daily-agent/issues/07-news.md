# 新闻推送

## 目标

在提醒和 outbox 稳定后，由 main 管理固定关键词和来源，定时生成带 URL 的新闻摘要。

## 实现范围

- 复用现有 Web Search/Tavily 工具，不新增搜索服务。
- main 可以提议关键词、来源和推送时间；新增来源需要 owner 确认。
- 搜索结果保存必要的 URL、标题、时间和摘要来源，不自动写入长期记忆。
- 同一时间窗口和 URL 去重；失败、限流和结果未知进入任务/通知状态。
- 新闻摘要通过 outbox 推送，低优先级事件可批量合并。

## 验证

- 推送内容包含可访问来源 URL；
- 重复搜索不会在同一摘要中重复同一来源；
- Tavily 不可用时不会伪造新闻事实；
- 新闻任务不会读取未授权项目资料或个人私密历史。
