# QQ 群聊与 chat agent 衔接

## 目标

把已有 NapCat 群聊规划接入新的角色和事件编排层，不让 QQ 群成员获得 main 的个人资料和控制权限。

## 实现范围

- 复用 `.scratch/personal-agent/issues/07-qq.md` 的指定群、明确 @、同群 FIFO、5 分钟过期和撤回处理规则；
- 每个“登录账号 + 群”绑定独立 chat Project/Session/工作目录；
- chat 仅接收本群触发交互，默认不注册 Shell、文件、MCP 或通用 HTTP 工具；
- 群资料与 main 个人数据、开发历史、个人共享记忆和项目指令隔离；
- 群聊摘要只有经 main 明确接收的结构化结果才能进入 outbox；
- 普通群回复不改变 owner 权限，不批准开发任务，不开启完全访问。

## 验证

- 群成员无法读取 main 数据、开发历史或凭据；
- 机器人自身消息和重复事件不形成回声任务；
- 撤回消息不进入后续上下文，未发送回复被取消；
- 跨群会话、队列和资料完全隔离；
- 真实群收发仍需拥有者单独授权，模拟测试不代表部署通过。
