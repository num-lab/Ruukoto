# 拥有者浏览解除 Agent 保护目录限制

Status: resolved

## 目标与边界

拥有者在 2026-10-24 明确要求「文件树读取、文件浏览和git扫描不应该受到这样的限制」，指前序诊断确认的后台保护根检查。三个拥有者查询不再遍历或拒绝后台数据、凭据、控制目录及代码根；Agent 工具、任务执行与工作区登记规则保持。保留登记根身份、相对路径、链接处理、分页修订、读取一致性与错误分类，Git 自身元数据检查和固定只读命令继续适用。无需再次确认此取舍。

## 方案

1. 从 `workspace-files.ts`、`workspace-git.ts` 删除保护根参数、保护辅助函数及调用；Runtime 三个入口不再计算或传入保护根。
2. 删除 `approved-ops.ts` 仅供这三条查询使用的 `assertDirectoryReadNotProtected`，保留 Agent 通用保护检查。调整 `desktop-workspace-files`、`desktop-workspace-git`、`desktop-live-files`、`dir-identity` 全部调用；删除旧目录保护专用用例，增加控制面允许浏览保护目录及不枚举无关树的回归。
3. 新决策笔记记录拥有者浏览与 Agent 执行的区别，与旧桌面读取／Git／目录保护决定互链；同步 desktop、runtime 模块文档，核对 execution 文档是否涉及被删除入口。
4. 运行 `npm run check:static` 及文件、Git、live-files、inspector 和 Agent 通用保护的定向测试。复测同一 535 行 HTML、目录和小 Git 仓库，使用隔离后台确认控制面行为，不重启日常后台。
