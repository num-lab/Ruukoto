## 目标与边界

## 方案

1. 渲染进程经 `subscribe` 得到快照与事件，交给 `@ruukoto/view` 投影；历史分页用 `read_history`。
2. 左栏：工作区与会话来自快照与 `list_session_summaries`；“添加工作区”用 `pickFolder` 后调用 `open_workspace`；“新建会话”调用 `create_session`，带 `request_id`。SubAgent 会话不出现在树中。
3. 中间：会话标签页的开合只是界面状态；对话流按 view 的流条目渲染，正文用 `react-markdown` 加 `remark-gfm` 且关闭原始 HTML。
4. 放行名单加入本单调用的 op。
