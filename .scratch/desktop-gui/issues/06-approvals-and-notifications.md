# 审批卡片、系统通知与 Dock 角标

Status: plan-review

## 目标与边界

实现[规格 R9 的审批卡片与 R12](../spec.md)。审批卡片两个目标共用；通知与角标由主进程按两个目标的快照与事件计算。

## 方案

1. 审批卡片显示快照中 `pending` 审批的有界预览，需要时用 `get_confirmation_params` 分段读取完整参数；批准与拒绝调用 `respond_confirmation`，带 `permission_version`；`stale_confirmation` 与 `permission_version_mismatch` 显示原因并刷新。
2. 主进程按目标统计待审批数，Dock 角标显示两个目标之和。
3. 窗口不在前台时，新的待审批或任务进入 `completed`、`failed`、`interrupted` 时发系统通知，点击通知后聚焦窗口并跳到对应目标与会话；窗口在前台时不发。
4. 放行名单加入本单调用的 op。
