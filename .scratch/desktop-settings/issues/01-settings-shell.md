## 方案

1. 从 `apps/desktop/src/renderer/app.tsx` 抽出设置容器，继续使用已有 Dialog、Tabs、Field、Input、Select 与 Button，修改 `style.css` 的浮窗尺寸和滚动；不另建路由或通用表单框架。
2. 模型/Skills/MCP 独立选择 Code 或 Personal，MCP 另选 Code 工作区；多原项目来源时增加按名称的配置来源选择，按规格选择默认值，显示写入归属。组件接收必要的 `CodeState` 与连接状态，不以当前聊天会话作为保存资格；来源候选由 03 后台接线。
3. 保留表单草稿、读取修订、提交状态及原目标关联；切换时处理未保存内容；采用已有代次淘汰方法，防止断线、关闭、换实例和迟到请求串写。明确错误与待核实状态，保存期间禁止重复动作。
4. 在页面具体操作接入时扩展所需状态，不预建任意操作调度器。给后续工单留明确的组件参数与状态归属说明。
5. 同步 `docs/modules/desktop.md` 的已交付设置结构；尚未接线的管理能力不能写为已可用。
