# 05 Code Skills 管理页面与受控目录选择

Status: ready-for-agent

## 目标与边界

接通 Code 的技能列表、诊断、正文预览、单包导入、托管启停/移除，遵守[技能边界](../spec.md#skills-管理边界)和 R1–R4、R7–R8。前置：[01](01-settings-shell.md)、[04](04-managed-skills.md)。

## 方案

1. 增 Skills 页，列表显示名称、描述、来源、启用/停用/仅显式调用与诊断；名称检索只在已取得列表内进行。选中后读取有界 Markdown 正文，沿现有不渲染原始 HTML 的规则；不运行脚本或自动加载远程图片。
2. Code 导入使用系统文件夹选择后展示后台预览；宿主绑定选择的目标、实例和路径，用户确认后提交该次选择，不能从 renderer 传任意路径当作已选目录。复用已有选择器与双壳宿主，不新增通用宿主文件 API。
3. 外部维护项只展示来源与诊断；托管项提供启停、移除及影响确认。明确停用从新任务选择生效、旧任务引用继续可读，移除不回收历史引用所需字节；冲突保留列表与选择，提供刷新比较；丢答读回，不自动复制第二份。
4. 在 `main/ipc.ts` 按 Code 白名单接通 04，`DesktopHost` 保证两壳相同行为；不扩大旧 Personal 的操作名单。更新 `docs/modules/desktop.md` 与 `docs/usage.md`。
