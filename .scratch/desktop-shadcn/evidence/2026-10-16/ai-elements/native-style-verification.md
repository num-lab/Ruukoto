# 消息流原生样式验收

2026-10-16；拥有者要求只把 demo 消息流改为 shadcn/ui 原生样式。沿用[已有组件替换](verification.md)，不迁移正式 Desktop，也不覆盖冻结稿。

## 范围与工程检查

主／子消息流移除旧气泡、活动行、审批卡与内联代码视觉覆盖，采用 Message、Bubble、Trace、Item 与 Button 的默认类；颜色使用官方 Neutral 明暗 token。局部恢复旧全局重置影响的字号、图标、圆角和焦点环；不修改组件原语或全局主题。正文保留在单个段落内，长路径限制在内容宽度内换行，审批命令可横向滚动、用途完整显示。

`npm --prefix .scratch/desktop-shadcn/demo run check` 与 `npm run check:static` 通过。只读独立审查无交互或范围阻断，发现的焦点环 token 差异已局部修复并在浏览器核对。正式 Desktop 源码、冻结稿、demo 原语、reference.css 与依赖锁共 80 个文件的哈希与本轮修改前一致。

## 浏览器检查

在既有 localhost demo 的默认 837×827 窗口验收，另以 760×500 检查窄窗，结束后恢复默认尺寸。所有审批均为内存模拟数据。

| 核对项 | 结果 |
| --- | --- |
| 其他区域隔离 | 左栏、顶栏、输入卡、textarea、模式选择器、提交按钮、右栏标签头和内容外框共 8 个区域，背景、前景、字号、行高、圆角、内边距、间距、阴影、底边、宽高共 11 项计算样式与修改前完全一致 |
| 原生消息 | 深色 Bubble 背景为 oklch(0.269 0 0)，浅色为 oklch(0.97 0 0)；字号 14px、内边距 10px 12px、圆角 22px；审批 Item 无旧背景与阴影，使用 outline 默认边框 |
| Trace 与键盘 | 工具组 Enter 展开，Read 无行范围；焦点环使用 Neutral ring，深色 0.556、30% 透明度；文件名旁保留增删数，点击文件打开原差异面板 |
| 子 Agent | 独立入口打开右栏，消息和正文使用同一原生样式；右栏标签、元信息与差异展示沿用原样 |
| 审批 | 批准和拒绝分别实点验证，决定后卡片消失，没有添加结果行 |
| 窄窗 | 两侧展开时主／子消息容器无横向溢出，长路径能换行；命令仅在 pre 内横滚，输入卡在窗口内；整页无横向溢出 |
