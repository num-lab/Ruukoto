# 侧栏宽度调节验收

日期：2026-10-16。对象为拥有者追加的「让侧边栏宽度可调节」，仍只修改 demo。[源码哈希](resize-source-hashes.json)覆盖 App、分隔柄、样式和渲染断言。此前固定宽度证据不证明本轮调节行为。

## 工程验收

`npm --prefix .scratch/desktop-shadcn/demo run check`、根 `npm run check:static` 与 `git diff --check` 均通过。

新增窄断言覆盖左右最大宽度、窄窗夹紧、另一栏闭合、空间不足，以及右栏已达 543px 时左栏仍可增宽；首屏具备两侧可访问分隔柄。独立只读审查发现 CSS 与 JS 的左栏优先规则不一致，修正后复核通过，审查者亲自执行 `node scripts/check-render.mjs` 通过。指针以当前 pointerId 归属，取消、丢失捕获、折叠和卸载释放拖动；这些取消路径由源码复核，浏览器工具未合成取消事件。

## 浏览器亲验

独立后台 QA 标签，保留拥有者预览。1003×827 下实际拖动左栏由 200 到 260px，右栏由 310 到 410px；松开后无拖动态，恢复 200ms 过渡。方向键与边界移动方向一致，连续 4 次右键由左栏 180 调至 244px，每次 16px。左栏向外拖超过下限停在 180px。

缩至 760×500：左栏 244px、右栏自动夹紧为 272px、正文 220px，页面无横向溢出。收起左栏后右栏恢复偏好 394px、正文 342px；重新展开左栏恢复 244px，右栏重新夹紧，扩大窗口又恢复偏好宽度。

在应用宽度 963px 下先将右栏拖至 543px，左栏分隔柄最大值仍为 360px；左栏再由 200 调至 260px，右栏收至 483px、正文仍 220px。最终调整为左 260px、右 355px、正文 348px，见[调整后截图](../../../git-history-cleanup/archive.md?path=.scratch%2Fdesktop-shadcn%2Fevidence%2F2026-10-16%2Fresized-sidebars.jpg)。分隔柄 ARIA 范围随布局更新，闭合栏仍 inert；不显示悬浮说明。控制台无 error 或 warn；结束后关闭 QA 标签并清除尺寸覆盖，保留拥有者原有预览。

## 范围

没有新增依赖，也未迁移正式 desktop。宽度只存本次页面内存，刷新重置。极窄窗口同时展开两侧时，侧栏下限可能占用正文空间；没有进行真实 Electron 验收。
