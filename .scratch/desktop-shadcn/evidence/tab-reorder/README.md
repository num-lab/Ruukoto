# 等宽 Tab 与拖动排序验收

日期：2026-10-17；范围：可变 demo 工单14，叠加工单12、13的未提交改动；环境：macOS、Node 24.15、IAB http://127.0.0.1:5173/，视口949 × 827。全部会话和差异均为既有模拟数据，验收草稿未写入fixture。

## 工程检查

`npm --prefix .scratch/desktop-shadcn/demo run check` 通过：类型、排序／渲染／提交自检、原稿来源核对和Vite构建。新增排序回归覆盖向前／后、无效与同位索引、原数组不变和右栏对象身份；两组顶部触发器均断言 draggable 与键盘快捷键。最初新增SSR断言误要求类名两侧空格，改为按class token识别后检查通过。原有单chunk大于500kB提示保留，无依赖变化。

`npm run check:static` 通过。末次实现改动仅给demo播报补充可读标题，并修正上述断言，随后重跑demo check通过；根源码未变。`git diff --check` 通过。

## 浏览器检查

通过Cua原生鼠标拖动实际移动标题，不注入拖放事件。断言和顺序／宽度原始结果见 [checks.json](checks.json)，最终完整可访问树见 [final-state.txt](final-state.txt)。

| 操作 | 结果 |
| --- | --- |
| 将首个Offline主标签拖到第三个位置 | 顺序变为MCP、Tokyo、Offline，草稿不变 |
| Offline按Alt+Shift+左方向键 | 移至第二位，保留选中与键盘焦点，播报标题及位置 |
| 拖动到消息区释放 | 不改顺序，源标签拖动态清除 |
| 从尚未显式选择过右标签的默认Schema Auditor开始键盘左移 | 变为Schema、indexeddb，仍显示Schema子Agent页面，不因末项改变而跳到diff |
| 从非活动indexeddb拖到Schema前 | 变为indexeddb、Schema，沿用原mousedown点击选中diff，显示原差异 |
| 主会话拖到右栏标签上释放 | 两组顺序均不变，拒绝跨组 |
| 关闭排序后的活动diff与主会话 | 按新顺序选择Schema／MCP邻项，无误关 |
| 重开Offline，打开PA并键盘调序，再返回 | Code与PA各自草稿保留，右栏状态隔离，PA无文件树／差异 |
| 调宽／收起侧栏与溢出标签列表 | 活动PA标签完整位于可视区，长列表保持横滚 |
| 非活动PA标题拖到消息区释放 | 顺序不变，PA沿用既有点击选中语义；返回Code后草稿和页面仍在 |
| 最终读取四个主标签与两个右标签尺寸 | 六个宽度均为180px，均无残留dragging属性 |
| 深色、浅色及恢复常用侧栏 | 文字、图标、叠加关闭和分隔线可见；见截图 |
