## 方案

独立 React、Vite、Tailwind v4 项目使用官方 shadcn 源码组件与 Lucide 图标。原稿的 CSS 变量、四组阴影、字体、三栏尺寸、48px 无边框标签头、650px 消息流与浮动输入区直接复用；左侧纯工作区树，用户气泡靠右，工具活动轻量折叠且 SubAgent 独立，右侧按文件与 SubAgent 开独立标签；顶部会话标签区从 main 提取，横跨对话与右栏，右栏在其下展开。移除被否定的品牌块、面包屑、大标题、分隔线、固定检查器分页与卡片化答复。

模拟数据直接取自原稿，模型、模式、草稿、继续来源和右侧标签按会话保存。保留新建、会话切换、关闭标签、命令参数常驻并直接审批、运行中排队、任务中断／继续、队列恢复确认、输入保留并自动核实后发送、连接失败、差异失败／空文件／截断、SubAgent 历史和 Personal 连接占位。工作区筛选只是原稿的前端预览；不将模拟筛选、演示状态选项、浏览器、全局搜索或差异接受／拒绝迁入正式业务。附件加号由新批注明确授权；当前只保存文件名和大小，正式迁移须补齐真实附件通路，不再沿用旧规格对附件入口的排除。

范围限 `.scratch/desktop-shadcn/demo/`、本工单与证据、[设计决定](../../../.agents/notes/implemented/architecture/2026-10-15-desktop-shadcn-demo.md)，以及 README、开发说明和提交前检查的导航。demo 有独立依赖锁文件，不影响根安装或 Electron 构建。
