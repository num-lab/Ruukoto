## 方案

删除 Step 的 thought 类型、注入样例、渲染和旧断言。主／子消息流共用一个工具活动组件：沿用 Trace 的摘要折叠分组，内容使用嵌套 Trace，各调用通过 TraceCollapsible 打开详情；Read 行不作为折叠按钮，只让文件路径可点击，失败 Read 的错误直接显示，满足不可展开与错误可见。分组包含失败时摘要也标明失败，避免收起后隐藏状态。展开状态沿会话／消息流／步骤键隔离，沿用已有 180ms 动画和减弱动画设置，退出区 inert／aria-hidden。

用已有 Session.diffs 和工具的 diffFile 关联 Edit／Write 片段，不从完整文件推导差异；缺失差异显示明确提示。工具样例可记录 command、output、error，失败由显式 error 判定，不解析文本。命令与输出、错误及差异复用官方 CodeBlock 的普通／destructive／行变体，复制实际使用的原语部分，不安装未使用的高亮 hook、复制按钮或新依赖。工具内容按文本渲染、长行换行、限制高度，不出现横向滚动条。Read 接已有 openFile，不跳到 diff。

保留默认对话数据；在已有设置的演示状态中增加工具详情样例，覆盖 Write、成功／失败 Bash 和失败 Read，不把虚构命令加进默认历史。对已有其他活动保留名称与已有数据，能提供参数／结果时展开，不能提供时保持静态行。README 同步用法；新决策笔记部分取代 AI Elements 的思考显示和工具跳转决定并互链。
