# Tab 拖动避让

Status: ready-for-human

## 目标与范围

拥有者在 2026-10-17 要求拖动 tab 时其他 tab 避让。沿用[等宽排序](14-tab-reorder.md)，只改可变 demo 的会话与右栏两组顶部 tab；保留既有未提交改动，不迁移正式 Desktop、不提交。

## 方案

保留原生拖放和180px等宽。拖动状态增加预览目标，原数组直到松手才变更；同组列表根据指针在原始槽位中的位置更新预览。相邻 tab 用 transform 过渡让出目标位置，源 tab 隐藏并沿用原生拖影；列表自身接收拖放，确保空位、关闭键和间隙可落下。目标由列表的布局位置计算，不追逐已平移的标签，避免来回抖动。

取消、移出或跨组不提交顺序并清除预览；右栏继续核实会话身份。松手沿用现有 moveTab，保持选中页、草稿、右栏对象与关闭逻辑；键盘排序保持。系统减弱动画时直接避让。无新增依赖。

影响 app.tsx 的两组列表与共用拖放接线、style.css、render自检、README和既有排序笔记；不改公共UI组件与后台。使用纯槽位偏移计算供定向自检，列表几何与拖动中的可见位置由真实浏览器验证。

## 验收

自检覆盖向前／后避让、未跨越项不动、源项与占位、缺失来源／目标不位移；原有排序、键盘与180px断言保留。运行demo check、check:static、diff检查。实际浏览器在松手前读取相邻项位移／占位，截图，松手确认新顺序；验证反向拖动、取消、跨组拒绝、右栏与会话状态、明暗及横向溢出。先独立方案审查再实施，完成后独立实现及证据审查；拥有者审阅避让观感。
