# Tab 动态等宽

Status: ready-for-human

## 目标与范围

拥有者在 2026-10-17 要求动态调整 tab 宽度，沿用同组等宽和拖动避让。只修改可变 demo 的会话与右栏两组 tab；保留其他未提交改动，不迁移 Desktop 或提交。

## 方案

每组 tab 根据自身可见标签区宽度与数量均分空间，上限沿用180px，下限96px；超过下限后沿用横向滚动。CSS 容器单位与每组标签数量计算宽度，不增加 JS 测量状态或监听器；开关侧栏、调宽、打开／关闭标签时自动更新。两组独立计算并保持各自等宽。

复用 --tab-width 让拖动预览步长同步实际宽度；落点计算改读未缩放的矩形宽度，避免 offsetWidth 整数取整在小数宽度时产生累计误差。保留选中显露、叠加关闭、短分隔线、拖动取消和状态身份。影响 style.css、app.tsx 共用 tabListProps 与 targetAt、render自检、README及宽度决策；不改公共UI原语，无新增依赖。

## 验收

运行 demo check、check:static、diff检查。浏览器测量两组标签在宽／窄／溢出时等宽、96至180px范围；开关侧栏、调宽、增删标签自动变化，活动项可见；小数宽度实拖避让与排序、取消、横滚落点，明暗截图。系统减弱动画沿用现有规则，不新增宽度过渡，避免拖动步长追逐动画值。先独立方案审查，完成后独立实现与证据审查，宽度观感交拥有者。
