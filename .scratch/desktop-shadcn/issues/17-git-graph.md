# 右侧栏 Git graph

Status: ready-for-human

## 目标与范围

拥有者在 2026-10-17 要求右栏新增 Git graph，并只在 Git 仓库显示。沿用当前可变 demo 的右栏新标签入口，支持独立 Git graph 标签，保留等宽、拖动、关闭与按会话隔离。本轮只做只读 GUI 样例，不调用真实 Git、不迁移正式 Desktop、不提交。

## 方案

用独立的工作区仓库样例描述是否为仓库及提交 DAG，区分非仓库、空仓库与有历史的仓库：fumo／nexus有历史，menubar为空仓库，eval及新工作区无仓库信息，PA无工作区。入口按仓库元数据存在性显示，打开函数再次核实；同一会话重复打开去重。空仓库保留入口并展示暂无提交。

图与提交列表共同显示在独立只读面板：SVG连接父子提交并展示分支／合并，行内显示提交主题、分支／HEAD标记、作者、日期与短哈希；适配窄栏并沿用主题语义色。提交行仅展示，不增加checkout、fetch、搜索、分支切换或提交编辑。样例面板标明只读样例，不冒充真实历史。

最小实现为git-graph.tsx与git-graph-data.ts（fixture、拓扑按序分配lane的纯函数），复用现有右栏tab装配；历史为新到旧拓扑顺序，节点与父边按实际提交关系计算。展示窗口外的父提交用延续线表示，不丢弃边。影响demo-data RightTab联合、App入口／守卫／面板、局部CSS、check-inspector自检、README和决策记录。不新增依赖、不改公共UI原语、正式模块文档或冻结稿。

## 验收

定向自检覆盖非仓库／PA／未知工作区、空仓库、线性／分叉合并／多根历史、截断父边、fixture父子顺序和图数据不变，以及SSR行数／元数据／文本转义／空态。运行demo check、check:static、diff检查。浏览器实际打开与去重、切换工作区／会话隔离、普通目录与PA无入口、空仓库空态、标签拖动关闭、明暗和窄栏。工程实现与证据经独立审查，拥有者审阅图形观感。
