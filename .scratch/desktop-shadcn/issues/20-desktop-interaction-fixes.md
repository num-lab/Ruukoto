# Desktop 拖动、渲染与文件预览修复

Status: ready-for-human

## 目标与授权

拥有者报告五处问题并要求修改：拖动标签偶发重叠、快速滚动消息流出现未绘制区域、文件树不反映磁盘新增／删除、Read 行的 /tmp 文件无法预览、新会话丢失 mode／model／effort。沿用上轮未提交迁移，不提交、不推送、不重启日常后台。Desktop 为实际目标，Demo 同步能表达的拖动与绘制修复，冻结来源不覆盖。

## 诊断与方案

Tab 已有实际 hook 事件重放红循环：预览后移出列表会让源项可见并执行回程，与相邻项交叉。先用原生／Demo 拖动帧核对该症状；保持源项从第一次预览直到 drop／dragend 隐藏，退出列表只取消目标避让。核实取消／重进／组切换和对象身份；只有证据显示原生拖影或结束事件遗漏时才增加相应处理。消息流先测实际 Conversation 的重复排序／Markdown 处理与屏外绘制策略，以会失败的渲染计数／规模基线和快速滚动证据区分原因；减少已完成消息的重复解析，避免快速滚动依赖临时占位，保留流式更新、prepend 锚定与工具链接。

文件树在活动 Files 面板刷新根及展开层，窗口聚焦与有界周期触发；关闭、切换面板或离线停止。请求去重、保留成功树静默刷新，错误明确可重试；沿实例／状态身份丢弃迟到结果，磁盘删除使相应文件缓存失效。后端继续使用现有受保护枚举，不增加常驻宿主 watcher 或扩大目录读取范围。

Read 工作区外路径使用该成功调用已捕获的 file_read 产物快照预览，通过既有 read_artifact 读取并核实 id／task／session 与完整状态；现有成功 Read 的唯一捕获流是 file_read，按该工具唯一 artifactId 识别，不解析产物人类名称；缺失或多义旧记录明确不可预览。不直接读取任意 /tmp 路径。保留有界读取、路径不可用／产物缺失／partial 的可见说明，原消息被捕获的版本即展示版本。只开放现有 control op 的 Desktop 最小白名单，无新系统路径权限。

新建会话在首次点击固定当前 Code 设置（mode 和含 thinkingLevel 的 ModelSelection），跨工作区仍继承同一 Code 选择；PA 前台时使用保留的最近 Code 选择，不复制远端模型目录。最后 Code 标签关闭后，在本次连接内仍保留最近 Code 来源；无来源沿后台默认。设置仍在保存或结果未知时先核实，不复制过期 Full access。create_session／open_workspace 增加可选 mode／model_selection，由 Store 初始字段与 session.created 在同一事务落盘；省略仍为既有默认。幂等重放保留首次创建成果、不覆盖后来修改，重试固定原键及设置；显式模型失效明确拒绝。effort 复用 thinkingLevel，不新增字段／schema；声明新参数并升协议，避免旧后台静默忽略。

## 影响与分工

根 checkout 唯一写入者为根代理，负责拖动、消息渲染、Demo 来源、汇总文档与证据。会话初始设置与文件树／Read 快照实现分别使用独立工作副本，基线精确复制根当前工作内容，返回仅本轮增量补丁，根应用后重定检查。独立审查只读。涉及 Desktop、Core、Runtime、Control 及各自测试／文档，View 投影只按实际需要更改；不添加依赖。

## 验收

五个准确症状各有最窄红转绿：Tab 完整生命周期无交叉可见源、快速滚动已加载消息不出现延迟空白且历史／流式更新正确、真实磁盘新增删除可见且停刷／去重／失败／迟到处理正确、外部 Read 在源文件删除后仍可看捕获快照且跨任务产物拒绝、新会话三条创建路径继承四种模式与非默认模型／effort且未知应答重试不漂移。运行 check:static、直接受影响回归、Demo check、MyGo Go race、MyGo 与 Electron 构建及签名；新增协议参数另加控制面／Core 初始字段与事件回归。真实 UI 使用隔离 MyGo／后台，不发送日常模型任务。外部 SSH／真实模型缺前提不记通过；截图与性能测量记录环境和样本。
