# Git graph 滚动自动加载

Status: ready-for-human

## 目标与边界

拥有者要求移除 Git graph 的加载更多按钮，改为自动懒加载。复用已实现的200条分页及 Inspector 去重、修订核实、迟到响应丢弃，不改后台协议或读取预算；本轮不提交、不推送，不重启日常应用与后台。Demo当前只有全部静态样例，无加载按钮，不伪造本机仓库分页。

## 方案

GitGraphPanel 在历史滚动容器末尾放置观察点，以该容器为 IntersectionObserver root，底部提前224px触发。仅面板可见且在线、有下一页、未刷新／追加、无错误时观察；首次不足一屏或追加后仍接近末尾时继续读取，直到离开观察范围或到末尾。每次观察回调至多触发一次；cleanup断开并忽略迟到通知。InspectorPanel显式传入展开且在线状态，切走Git标签卸载观察；工作区切换按key隔离。加载中用状态文本，失败保留已有历史、停止自动触发并显示错误与重试；刷新失败用已有刷新按钮恢复。

## 验收与证据

工程验收通过：旧组件的观察回归准确失败，新版通过，覆盖远离／接近末尾、同cursor无关更新、重复通知、追加继续、最终页、加载中、错误、隐藏／离线与卸载。定向43项、check:static、Demo check、MyGo／Electron构建及签名均通过。真实浏览器加载正式GitGraphPanel及正式CSS，用405条受控数据执行：顶部200条／0次请求，滚到底失败后200条／1次请求且停住；点击重试后400条／2次请求；再次滚到底405条／3次请求，末页再滚动不追加，无加载更多按钮。详情见[证据](../evidence/git-lazy-loading/README.md)。

产品验收的自动触发行为已在真实IntersectionObserver中验证，没有新增视觉取舍；原生MyGo尚未实测，保留人工体验复验，不把受控数据当真实后台或浏览器结果当原生结果。临时标签、HTML与验收服务已清理，日常Demo／后台未重启，原两个用户标签未操作。拥有者可复验原生滚动体验；无待确认的实现方案。
