# 文件树加载反馈与侧栏折叠

Status: ready-for-human

## 目标与边界

拥有者要求文件树首读改为加载图标、文件夹读取中只在行末显示图标且完成后展开，空目录无“暂无文件”；右栏新标签页删除Git检测中的文字及工具差异整栏，保留消息工具入口；修复左栏折叠按钮先右跳再左移。同步Demo与Desktop的对应展示，不改后台协议、读取权限、缓存和刷新周期，不提交、不推送、不重启日常后台。

## 方案

Directory使用已有loading/value/error；目录点击先记录展开意图并直接启动读取，实际Collapsible在有value或error后才展开；再次点击加载中的文件夹可撤销展开意图。行末loading图标带可访问名称，初始根目录使用独立状态图标；缓存已有内容可直接展开，后台刷新保留现有展开与内容。读取失败后显示错误和重试，不静默隐藏。空根／空子目录均不输出空文本。Demo使用同步fixture，无假延迟，只同步空目录及新标签页展示。

折叠按钮改为app-window中的单一定位按钮，展开时left为侧栏宽度减42px，折叠时Demo为16px、Desktop为84px以避开原生交通灯，left与侧栏同为200ms ease；保留同一DOM和焦点。顶栏保留按钮占位，宽度拖动时禁用定位过渡，减少动态偏好沿用现有全局规则。新增小CSS差量同步两端并更新来源断言，不改冻结v4或共享原语。
