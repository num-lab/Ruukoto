## 目标与边界

拥有者要求在打开 GUI 连接后台的阶段显示全屏加载遮罩，先在可变 Demo 实现。沿用当前明暗主题与毛玻璃风格；居中显示 Ruukoto、旋转加载图标与「正在连接后台…」。本轮不迁入 Desktop，不连接或修改真实后台，不显示虚构进度。

## 方案

App 首次打开进入连接状态，用约 2 秒的可清理计时器模拟就绪；复用已安装的 shadcn Dialog，内容铺满视口，无关闭按钮，阻止 Escape 与外部点击关闭。加载期间底层不可点击或聚焦，暂停 App 全局快捷键；就绪后淡出并聚焦输入。设置的演示状态提供重播入口，关闭设置后重播。减少动态效果时关闭旋转及过渡。

只改 Demo App 与加载组件、全局样式、样式差量快照、Demo 首屏检查与 test/43 的来源拼接断言，并同步 Demo README 与决策笔记。工程验收使用 Demo check、根 check:static、test/43，以及真实浏览器的首屏、自动关闭、重播、键鼠隔离和明暗检查；减少动态效果核对媒体规则，不改系统设置。
