# 通用定时任务规格

实现与验证由关联工单记录。决策依据：[调度计划只触发独立的通用任务](../../.agents/notes/implemented/feature/2026-10-12-generic-scheduled-tasks.md)。实施与验收见[工单 01](issues/01-generic-scheduled-tasks.md)。

实施状态：已完成并与关联工单联合验收，详见[验收报告](validation.md)；旧配置、旧 schema 与退役计划不做转换或授权回填。

## 目标

个人助手 ruukoto 只提供通用调度：时间规则加任务说明，每次到期在独立上下文执行。新闻、提醒及其他业务由任务与已有工具完成，删除内置新闻和定时固定通知路径。

## 已确认行为

| 范围 | 交付行为 |
| --- | --- |
| 产品与时间 | 仅 ruukoto；沿用一次性、每日、每周、IANA 时区及 DST；修改仍取消重建 |
| 输入与能力 | 每次新的执行上下文，输入为计划说明及明确提供的资料；不自动复制主聊天或前次历史，保留个人助手业务能力与委派资格 |
| 权限 | 保存创建时模式，触发及委派沿用；会话默认变更不改写已有计划；单次批准与长期授权不继承 |
| 审批 | full-access 免审批；受限任务按原策略暂停并向绑定入口请求决定，无 IM 时从 TUI／控制面处理，不阻塞主聊天 |
| 回报 | 创建时固定拥有者目标；每次整项运行结束默认回报一次最终结果或失败，不推中间过程；无 IM 留记录，目标失效不改发 |
| 运行范围 | 首次执行、派生工作／子任务、消息及最终汇总均属于同一次调度运行 |
| 重叠与漏过 | 同计划最多一项未完成运行；忙碌时合并到当前运行，离线且无在途运行时最多补最近一次，不建补跑队列 |
| 取消 | 停未来触发并取消排队、在途、等待审批的整项运行及子任务；保留记录、成果与未核实占用，外部效果不回滚 |
| 替换方式 | 无旧 news／notify 参数兼容、计划转换、字段回填或过渡双路径 |

## 与其他能力的关系

保留普通搜索及其供应商参数、一次消息发送、outbox、owner 回复、审批回执和 GitHub 汇报；不增加业务插件框架或 Coding Agent 调度入口。运行时身份必须支持已有个人业务工具，不能用缺少这些能力的普通 dev／SubAgent 会话代替，也不能伪造 main 绑定。

本工单负责调度存储、独立执行、审批来源、整项生命周期和回报。[完全访问工单](../full-access/issues/01-full-access-current-account.md)负责共享执行与免审批，双方共同验收计划保存创建模式；不再适配新闻 approvalId 或定时固定通知审批。实现时同步当前文档与决定，规划阶段不改写旧笔记的已实现行为。
