# TUI 与断开重连

## 目标

提供类似 pi agent 的终端交互，使用后台任务接口而不在 TUI 内持有执行循环。

## 实施范围

- 复用 01 确定的 TUI 能力，提供项目与会话切换、输入、流式结果、工具输出、排队状态、明确中断和中断任务的继续操作。
- 显示审批请求及其参数，允许拥有者批准或拒绝；展示当前权限模式，完全访问必须通过明确的拥有者操作开启。
- 退出与断开只关闭客户端，提供重新连接现有任务的入口；后台不可用时准确显示连接状态，避免悄悄另起同一任务。
- 提供历史查看及展开完整工具输出的入口，和 Agent 的历史读取能力使用同一资料来源。

## 交付与验证

在真实终端检查流式输出、审批、会话切换、退出和重连。后台执行一个持续任务时关闭 TUI，再连接后应看到持续执行的状态；输入重发不能重复启动任务。避免只用组件快照声称整个交互已验证。
