# 上下文、历史检索与长期记忆

## 目标

实现[完整历史与独立上下文](../../../docs/adr/0001-preserve-session-history.md)，使拥有者可以修改选择规则和记忆策略。

## 实施范围

- 按模型预算组装系统与项目指令、当前任务要求、最近完整交互，预留模型回答与工具结果空间。保持工具调用和结果配对，不能原地修改历史。
- 必须保留的内容自身超出预算时，明确暂停并给出原因；不能偷偷引入摘要。超长工具结果采用有原文引用的有限视图，完整正文继续可查。
- 提供按消息标识或范围读取原文及基础搜索；先使用现有存储和简单索引，不把向量数据库列为依赖。以项目范围过滤读取，跨项目必须显式开放，QQ 使用独立范围。
- 长期记忆保存个人偏好、项目约定、确认后的决策和经验，关联来源及修改记录，支持修改与撤销；临时进度保留在会话中。记忆不能改变执行身份、权限模式或审批规则。
- 记录每轮选入和排除的消息标识及原因，供调试和后续 Jev 对比；更换选择策略不改写历史。不自动删除原始历史。

## 交付与验证

构造超过预算的长会话，验证早期原文可定位、工具消息仍配对、预算不足时行为明确。检查原始内容保存完整、跨项目检索不泄漏未开放内容、记忆修改可以撤销；用真实开发任务观察效果，不设置硬性成功率门槛。
