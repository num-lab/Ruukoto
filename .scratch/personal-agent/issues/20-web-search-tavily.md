# 添加 Web Search 工具，首版适配 Tavily

## 目标

为个人 Agent 增加受控的网络搜索工具，首版接入 Tavily Search API，使模型可以在需要实时信息时获取带来源的搜索结果。

## 背景

当前项目已有会话历史搜索，但没有面向互联网的搜索工具。网络内容属于外部不可信资料，搜索结果只能作为模型上下文和用户可查来源，不能改变任务权限、审批策略或项目指令。Tavily 文档提供搜索结果摘要与 URL 来源，首版只接入 Search，不同时加入 Extract、Crawl 或 Research 工作流。[Tavily 文档](https://docs.tavily.com/)

## 实施范围

- 增加一个稳定命名的普通工具（建议 `web_search`），通过拥有者配置的 Tavily 凭据调用官方 Search API。凭据只保存在 `CredentialStore`，不进入模型上下文、搜索参数、历史正文、产物预览或日志。
- 首版只支持同步搜索：查询文本、有限结果数、可选主题/时间范围/域名过滤及安全的搜索深度参数；最终参数以 Tavily 实际 API schema 核实为准。禁止模型传入任意 URL 作为 API 目标，目标主机固定为 Tavily API。
- 每条结果保留标题、URL、摘要、发布时间（若有）和来源顺序；结果带服务名、查询时间、请求参数摘要及截断状态。对 URL、标题和摘要进行有界清理，外部内容中的指令不得被当作系统或拥有者指令执行。
- 搜索工具复用现有工具注册、任务身份、上下文预算、产物存储、取消、超时和事件记录。超过响应或上下文上限时返回明确的截断信息，不能静默丢弃来源或伪造完整结果。
- 网络读取仍受现有访问模式约束：首版将 Tavily Search 作为默认注册、可由拥有者按项目显式禁用的只读外部服务；任务开始固定工具清单，禁用立即阻止后续调用。服务未配置、凭据缺失或请求目标不匹配时拒绝调用。写工具审批规则不因搜索工具改变。
- 支持限时、取消、限流、认证失败、服务错误和部分响应；搜索请求结果不明时不得自动重复请求造成费用或配额消耗，重试必须有明确的幂等/安全边界和次数上限。
- 搜索结果默认只进入当前任务上下文，不自动写入长期记忆或跨项目资料。若保存完整响应或页面正文，使用带任务归属的 `ArtifactStore` 并遵守资料授权；默认不保存 API 密钥、完整请求头或无关结果。

## 已确认范围

- 直接调用 Tavily Search API，不通过 Tavily MCP；复用现有普通工具、`CredentialStore`、任务身份和结果记录路径。
- Web Search 默认启用并注册到新建及现有项目；拥有者可按项目显式禁用。任务开始固定工具清单，禁用立即阻止后续调用，新配置从下一任务生效。
- 已启用项目允许模型按需自动搜索；未启用项目不注册工具，也不发送 Tavily 请求。
- 首版上限为：每次最多 5 条结果、查询最多 500 个字符、每任务最多 5 次搜索、单次超时 15 秒、单次响应最多 256 KiB。超限返回明确错误，不自动增加额度。
- 开放查询文本、`general/news` 主题、时间范围和域名白名单；不开放 Extract、Crawl、Research、异步任务或任意 API 地址。
- 只提供模型工具，不增加 CLI/TUI 独立搜索命令；TUI 展示工具调用、来源和错误。
- 工具结果始终保留标题、摘要和 URL；最终回答引用搜索事实时必须附来源链接。搜索结果不自动视为已核实事实。
- 不做跨任务缓存，不自动写入长期记忆；仅保留当前任务的有界结果和来源，完整响应按需写入任务归属的 `ArtifactStore`。

## 验收标准

- Tavily 凭据配置后，默认启用的项目任务可发现 `web_search`，完成一次真实搜索并在结果中看到标题、摘要、URL 和查询时间；显式禁用的项目不会发送网络请求。
- 使用本地模拟 Tavily API 覆盖参数校验、域名过滤、分页或结果上限、认证失败、限流、超时、取消、畸形响应、超大摘要和外部提示注入；断言凭据不泄漏、结果有界且调用次数可核对。
- 搜索结果进入上下文时计入工具定义与内容预算；截断、无结果、部分失败和服务不可用均有明确状态，不把搜索结果当作拥有者指令或权限依据。
- 同一任务取消、后台重启或响应不明不会自动重复搜索；任务历史、事件和可选产物保留来源信息，跨项目和长期记忆不串用。
- `confirm`、`full_access` 和 `auto-review` 的权限边界不因只读搜索工具改变；模型不能通过查询参数访问任意外部主机、读取凭据或开启其他工具。
- 运行 `npm run typecheck` 和受影响测试；真实 Tavily 连通性验证记录服务版本/端点、配置范围、查询次数和结果限制。缺少凭据时明确列为未验证，不用模拟服务宣称真实接入完成。

## 实施计划

计划日期：2026-09-22。按已确认范围实现单一 `web_search` 普通工具；不引入 Tavily MCP、浏览器自动化或第二套 CLI/TUI 搜索流程。

### 1. 固定 Tavily API 与配置边界

- 在 `src/agent/web-search.ts` 集中实现 Tavily Search API 薄适配层，使用 Node 标准 `fetch`，固定 HTTPS API 主机和路径；不接受模型提供的 URL、请求头或 API key。
- 复用 `CredentialStore` 保存 Tavily 凭据，增加/核对目标 host 与操作用途（建议 `tavily_search`）限制。凭据由现有可信控制面配置，值不出现在工具参数、事件、日志、历史或错误中。
- 为项目保存 Web Search 的启用状态和配置版本；默认启用，拥有者可显式禁用。任务创建时固定启用状态和工具清单，禁用后阻止新调用，新增配置从下一任务生效。只有确有持久化缺口才新增项目配置列/表及 SQLite 迁移，不另建供应商配置系统。

### 2. 注册工具并绑定任务身份

- 在 `src/agent/driver.ts` 的 `ensureSdk()` 装配 `web_search`，复用现有宿主工具身份绑定；调用必须绑定项目、会话、任务和配置版本，不能落入 mock `confirmTools` 或通用任意 HTTP 路径。
- 工具参数仅开放 `query`、`topic`、时间范围、域名白名单及 Tavily 实际支持的安全搜索参数；服务端强制 `max_results <= 5`、查询长度 <= 500、每任务最多 5 次，拒绝未知字段和超限请求。
- 将工具定义、搜索结果和截断状态纳入现有上下文预算；结果默认只作为当前工具结果返回，不写长期记忆、不做跨任务缓存。完整响应只有在需要核查时写入任务归属的 `ArtifactStore`。

### 3. 处理来源、错误与外部内容

- 将 Tavily 返回的标题、摘要、URL、发布时间和顺序转换为有界结果，固定服务名与查询时间；校验 URL 结构并限制字段字节数。外部摘要中的指令按不可信数据处理，不拼入系统提示或权限配置。
- 使用 15 秒 `AbortSignal` 超时并传递任务取消信号；处理认证失败、限流、服务错误、空结果、畸形 JSON、部分结果和 256 KiB 响应上限，返回可解释的错误码与截断标记。
- 结果不明时不自动重试；若未来增加安全重试，必须按次数和费用预算单独变更验收。任务取消、后台重启或连接断开不得重复发送同一搜索请求。
- 在工具事件和 TUI 展示中保留来源 URL。模型引用搜索事实时通过提示/结果格式要求附来源链接，但不把搜索结果标为已核实事实。

### 4. 验证与交付

- 增加 `test/20-web-search.test.ts`，注入本地模拟 Tavily API，覆盖默认启用/项目禁用、任务清单冻结、参数校验、5 条结果、500 字符和 5 次任务上限、域名过滤、认证失败、限流、超时、取消、畸形响应、超大摘要、外部提示注入及凭据脱敏。
- 覆盖跨项目调用拒绝、任务权限和模式不被搜索工具改变、结果计入上下文预算、产物归属、重启/响应不明不重试，以及搜索 URL 不被改写为任意外部 API 目标。
- 真实 Tavily 验收只在拥有者配置凭据后执行一次受控查询，记录端点、工具版本、调用次数、限制和来源；没有凭据时明确保留未验证项。
- 运行 `npm run typecheck`、新增测试及受影响的上下文/生命周期/凭据测试，最后运行一次 `npm test`；同步更新 `docs/runtime.md` 的配置、禁用、限额、来源与故障处理说明。
