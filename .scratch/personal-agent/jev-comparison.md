# Jev 固定历史对比

日期：2026-09-25。本记录为合成中文历史的离线回放，使用本地预设决策和 HTTP 模拟服务，没有向 TypeSafe 提交真实任务或验证账户资格。公开 API 与条款已在本轮重新复核，背景见 [接入前核实](jev-research.md)。

固定样本 `jev-history-v1` 的可执行定义位于 [test/52-jev.test.ts](../../test/52-jev.test.ts)，测试名称为“Jev 合成中文历史回放：旧事实重新进入视图，必留与工具配对完整，原消息不变”。样本含 10 条消息，时间戳固定为 0，工具名称与参数固定为 `read` 和 `package.json`。预算为全量消息的本地估算减去索引 0–2 的估算，校准系数为 1，两个策略使用同一份冻结输入和同一预算。

消息数组经 `JSON.stringify` 后的 UTF-8 SHA-256 为 `378a089e6caf629eca3edce92ce13a9f6b733d9607c705953fee61406031e2d9`；测试会输出该摘要，便于识别样本变化。

| 原消息索引 | 内容与分组 | 基础规则 | 预设 Jev 决策后的视图 |
| --- | --- | --- | --- |
| 0、1、2 | 确认构建命令的用户消息、工具调用及结果 `npm run build`；`unit_0` | 排除 | 保留 |
| 3、4 | 临时天气的用户消息与无关回答；`unit_3` | 保留 | 排除 |
| 5 | 当前要求“找回已确认的构建命令” | 必留 | 必留 |
| 6、7 | 当前任务较早的工具调用及无关目录结果；`unit_6` | 保留 | 排除 |
| 8、9 | 最新工具调用及查找 `package.json` 的结果 | 必留 | 必留 |

基础规则 `deterministic-v1` 的选入索引为 `[3,4,5,6,7,8,9]`；实验取舍为 `unit_6=false`、`unit_3=false`、`unit_0=true`，得到 `[0,1,2,5,8,9]`，排除 `[3,4,6,7]`，原因为 `jev_rejected`。预先指定的信息点只有一个：已确认的构建命令。它在基础视图中不存在，在预设实验视图中存在；这说明本地筛选路径能够重新纳入较早事实，不能证明真实 Jev 会作出相同决策，也未测量主模型主动查询历史的成功率。

离线断言验证两种选择使用同一预算，实验结果未超预算；当前要求和最新完整工具批次保持存在，所有选入的 `toolCall` / `toolResult` 配对完整。输入递归冻结，选择前后 JSON 完全相同。另有运行时集成用例检查会话 JSONL 的既有字节前缀及产物原文保持完整，记忆和跨项目来源撤销后不会继续注入。

HTTP 合约用例单独固定模型为 `jev-1.13.0`、阈值为 0.5：模拟回答 `0.5` 保留、`0.49` 排除；模拟用量为输入 1,000、输出 20 tokens。按记录的 2026-09-25 单价 US$0.042/百万输入 tokens，算术估算为 US$0.000042。用量是测试输入，不是 TypeSafe 用量或账单；此数字不能作为本样本的实测费用。
