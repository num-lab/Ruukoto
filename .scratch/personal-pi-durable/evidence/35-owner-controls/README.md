## 能力入口矩阵

CLI 从六个操作分组进入已有管理函数，内部键、版本和请求键由程序保存。所有在线操作经本机认证接口，不再开Harness；停机配置持实例锁。下表中的“原菜单”均指当前原平台、账号、拥有者及代次下已送达的宿主消息；转发、摘录和普通聊天不提供批准资格。

| 能力 | 配置、查看和撤销路径 | 运行中操作与适用IM |
| --- | --- | --- |
| provider/model、图片能力 | 停机配置→模型；凭据只填环境变量名；实质更换须先完成原输入/工作，拒绝保留原文件 | 实例状态；IM `/状态`；不会修改旧输入权限 |
| QQ/Telegram | 停机配置→对应入口，配对/停用均换代；凭据变化重新配对 | 实例状态→收发；`/帮助`、`/状态`；旧回复不改发 |
| 模型、HTTP、搜索、MCP及IM凭据 | 环境/私有文件由后台部署持有；向导不收密钥值。HTTP绑定可移除，Tavily可停用，MCP可移除/重新选工具，IM可停用 | 原审批消费前复核配置与凭据；轮换不能重放原未知操作 |
| MCP | 停机配置→MCP：发现、逐项选择、替换或移除 | 审批核实→MCP；IM `/MCP`：原定义/请求/响应、批准拒绝、业务效果和原远端结束分别核实 |
| 资料与网络、只读资料授权、产物 | 停机配置→资料与网络；权限/资料→工具管理→资料授权可新增或撤销 | 原工具操作、产物分页/完整导出；IM `/工具`；导出不覆盖已有文件 |
| 模式、长期服务授权 | 权限/资料→默认模式与长期授权；本机与TG共享默认，QQ独立；完全访问明确二次选择。长期授权本机只查看/按原版本撤销，显示外部账号及当前/旧绑定 | IM `/权限`、`/授权`；创建长期授权只允许原待审批菜单中的具体服务范围；历史工作不扩权 |

| 命令目录 | 停机配置→命令目录；首次固定目录身份/机器/TMPDIR，不提供换目录或删除证据入口 | 原命令双流、效果和停止；IM `/命令`。不在IM创建任意宿主命令；只管理已有子工作命令 |
| 浏览器、图片 | 停机配置→浏览器和模型图片选择；浏览器运行能力沿新输入模式，已有完全访问工作/计划须单独取消 | 浏览器管理可关闭原浏览器，核实网页效果并读截图；IM `/浏览器`。停止与业务效果分开，图片不能作为批准 |
| 后台工作与长期子身份 | 模型沿当前拥有者来源委派，无需内部ID；身份关闭后历史保留 | 工作/计划→单项分析与分析委托，追加/取消/关闭/完整报告；IM `/工作`、`/委托` |
| 定时计划 | 工作/计划→逐步创建、核实上次创建、查看或取消 | IM `/定时` 同样按草稿/确认菜单创建、查原运行/报告、整项取消；配置变化后原计划停止新执行，先核实再取消重建 |
| 技能 | 停机配置→技能库；拥有者维护外部库，目录及正文动态刷新；更换库保留历史快照 | 本机配置可查看目录；主会话显式 `/skill:名称 参数`，技能不能增加权限 |
| 长期记忆、历史 | 权限/资料→记忆或历史，可不经模型查询/保存/修订/撤销记忆、读取历史 | IM主会话工具及显式技能沿已有接线，不复制记忆审批状态机；撤销记忆不删除历史 |
| 应用数据 | 随独立档案初始化并固定业务库身份，无任意SQL配置入口 | 审批核实→应用数据；IM `/应用数据` 原操作批准/拒绝、完整回执与恢复原库后重核；子资格沿当前委派 |
| 后台与诊断 | 实例状态/启停、最近消息、核实上次提交和受保护backend.log | 连接失败不证明停机，原未决文件保留；只查原键，不换键重发 |

服务路径和命令目录保持已确认的不可变恢复约定；改变部署需要保留原档案和原环境完成核实，再使用独立新档案。模型/Tavily秘密的实际撤销和轮换由对应服务及后台启动环境处理，CLI管理引用及能力配置。不存在把普通聊天解析为停用、批准或新授权的捷径。

## 配置与恢复契约

统一空闲检查复用技能配置已有的精确监督任务豁免：原索引ID、Task kind/version、根会话、后台归属、无owner及空参数全部一致才放过。未结束定时运行、普通活动任务和queued/placed输入仍拒绝；各能力的未核实效果/停止检查保留。模型保存比较完整规范化配置，保存前失败保留原文件；相同配置可供恢复。QQ/TG换代停用不被未决审批阻止。

命令控制复用原命令Task与停止任务；效果证据绑定原控制收件，停止任务固定原控制收件并在执行/abort核实前重查入口活性。旧代次只终结该控制任务，不外调。主会话 `personal-owner-controls` 扩展使旧程序拒绝忽略新语义；恢复双向检查菜单、效果actor/receipt、原停止Task和admission。所有重投、查询与重开都不重新执行命令。
