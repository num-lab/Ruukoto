# 37 命令中断观察器审查

2026-10-18，独立上下文 linux_preflight 核对 `observe-command-crash.py`，修正后无阻断。观察器只绑定本轮记录的测试 serve，使用 pidfd 固定身份；暂停后重新读取一致快照并核对原工作、命令、报告、原执行指纹与 cgroup，再中断。没有报告先行接纳、已有结果、其他独立后台未结束或停止对象不符均拒绝注入；中断前失败恢复原进程。

独立无信号自检覆盖：最终核对失败时仅恢复、不写记录；成功时先证明退出再保存 injected；退出未证明及发现已提交 observation 时不保存 injected。两个外部查询均有 5 秒超时。实际 Node 表达式的合成输入核实两类指纹，命令变化只改变 command 指纹，执行输入变化同时改变二者。自检没有发真实信号、联网、写文件或读取 private。

该结论仅为观察器审查，真实场景是否达到窗口及恢复结果须以现场记录为准。服务结果修复后测试后台更换代次时，运行前还须固定新 PID/starttime 与记录文件并复核。
