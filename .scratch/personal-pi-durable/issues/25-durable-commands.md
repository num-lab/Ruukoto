# 个人受限命令归原工作持有

Status: ready-for-human

## 目标与边界

接续[总工单](01-migration-plan.md)及[宿主回执](24-command-execution.md)，将 Linux 受限命令接入 durable 子工作，覆盖原授权、执行意图、结果与停止、未知暂停、工作取消和报告恢复。依据[规格](../spec.md) A3/A5/A6/A8/A9/A10，沿用已确认产品范围。完全访问没有持久停止原语，本片在命令准入前明确拒绝该模式，后续独立补齐；不改 Coding、正式入口或部署，不计完整迁移或完整三模式验收。

## 方案

- 停机持锁配置独立命令目录，保存 realpath/dev/ino；不由模型提供目录、权限或执行引用。固定个人自包含 worker、空运行依赖和保护根。证据放私有档案子目录，档案锁只增加精确允许项并保留普通目录及权限校验。首次启用前拒绝未决输入/工作，已有配置不可换目录。
- 子工具接纳先核实活动 tool/generation、原工作输入与权限，原命令、来源、work、LinuxExecutionRef 和原生 owned Task 同 commit 持久化，另存不可改接纳 entry。Task 由 WorkTask 持有，工具取消不销毁未知事实。命令仅在原目录、受限网络及已有范围执行，越界能力仍不可用。
- prepare 后将完整 spec/input 与预期请求指纹在执行前同 commit 保存并进入恢复阶段，再调用宿主 API。原任务恢复只读回执并按原引用停止，绝不再次 prepare/launch。严格停止要求原请求与原 launch 指纹，缺原认领、指纹不符或只有 stop 先手均保留占用，不新建替代认领。回执逐项核实原预期指纹，输出按原始双流有界分页读取，结果是运行返回而非业务成功。无回执/损坏证据保持未知；停止事实独立保存。
- 正常/取消各条 WorkTask 收尾等待所有命令，最终释放事务再核实全部 Task 与未知/停止事实。取消先持久标记；终态异常也保留占用。跨成员、原输入、追加、续派、子模型、固定检查及服务准入/消费统一识别命令未知暂停；主聊天和独立工作继续。
- 报告 watch 与暂停恢复核验增加命令类型。Harness 在 resume 前核对配置/扩展、双向 task/doc/admission/toolCall/work/source 关系、原 worker 与预期指纹；空闲档案原子升级，旧程序与未决旧档案拒绝误恢复。
- 本机认证管理接口及选择式 CLI 提供命令列表、原始证据、人工效果说明和原引用停止重核；控制动作由程序管理内部键，原效果说明不可覆盖，不以人工说明代替 OS 停止。Telegram 原工作可从本机管理核实，不开放模型解除暂停。
- 新窄用例覆盖原权限与来源、同键恢复、回执提交窗口、中断不重发、取消/最终释放竞态、跨成员/服务/报告暂停、坏恢复记录与输出分页。执行 static、build、相关 personal 回归及产品入口；Linux 用 ssh tx 验证真实受限命令、强杀恢复、原 scope 停止并清理独立目录。真实模型/IM 与产品体验单独记录待验。
