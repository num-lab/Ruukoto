# 个人 MCP 配置、调用与持久恢复

Status: ready-for-human

## 目标与边界

把共享 HTTP 传输接入个人 durable 主/子工作，完成拥有者配置、工具钉版、凭据核实、审批、原响应、取消和未知效果处理。覆盖 A3/A5/A6/A7/A8/A9/A10；沿用现有 HTTP 范围，不扩展 stdio、OAuth 或 MCP 客户端代执行能力。

本单承接[已确认规格](../spec.md)；当前基线、共同实施规则与验收分工见[剩余工作评估](../remaining-work.md)。拥有者于 2026-10-17 指示接手实施；工程实施、自动检查与独立审查已完成；真实 MCP 服务、真实模型/IM 和产品体验保留待验。

## 方案

- 复用 `packages/agent/src/mcp/transport.ts`，在个人 app 配置服务端点、凭据引用、工具允许列表与配置代次；首次启用和变更复核未决工作，缺凭据不能降级匿名。不得为复用连接伪造旧项目或 CredentialStore。
- 原工具定义、参数、来源、权限、目标与调用键在外调前写入 durable；执行状态直接使用原生工具 Task，完整原响应与失败事实持久化，不另建文件 journal 或复制旧 MCP ToolRouter。工具只读标注不作为权限依据，写/未知工具沿既有逐次授权。
- 把 MCP 纳入工作正常/取消收尾、跨工具来源暂停和报告恢复。HTTP close/abort/超时仅表示本地等待结束，不能当远端结束；完整原请求响应或可核实的远端请求结束证据与业务效果分别登记。缺证据时保留未知和占用，不自动重发或换键解除。
- 提供原入口审批、结果分页、效果与原请求结束证据查询/核实；配置、主/子工具及模型可见文本同步 `personal-harness.ts`、work/delegation/report、CLI/Telegram 和 personal-durable/usage 文档。跨工具最终体验由 35 汇总。

### 当前实现

- `personal-mcp-config.ts` 在停机锁内配置端点、逐请求私有凭据文件引用与钉版工具允许列表；durable 保存配置代次历史。首次启用、变更及代次复用检查未决输入、工作与外部占用；远端只读标注不提供权限。
- 主/子模型共用 `mcp_tools`、`mcp_call`、`read_mcp_result`，调用直接使用原生 `pi.tool` 身份；共享纯 schema 模块不加载旧工具装配。原 JSON-RPC 请求与批准消费在真正 fetch 前同事务持久化，恢复不重发；完整原响应包括 isError、结构化/非文本和 error.data，按原调用分页读取。
- 工作正常/取消、委托、报告及服务/命令来源门接入 MCP 未知暂停；原子身份与归一 origin+pathname 端点占用保留，查询参数等 URL 别名不能绕过。主聊天及其他独立来源/端点可继续。
- 只有完整匹配的终结响应才能核实远端结束。原 session/protocol/SSE 游标齐备时由原生后台核实任务只 GET 原流；游标与同事件原响应一起落盘，迟到失败仍保持原失败分类。人工业务效果核实不可覆盖且不设置远端结束；缺恢复证据持续保留占用。
- 本机认证控制面、引导式 CLI 和原 Telegram 宿主菜单均已接通；未装配 MCP 时只返回配置指引，不生成无法恢复的菜单。决定与效果核实反向核对原控制收件，恢复审计最新观察、批准和核实证据的双向关系。
- 决定与备选见[个人 MCP 笔记](../../../.agents/notes/implemented/architecture/2026-10-17-personal-durable-mcp.md)，同步 personal-durable、agent-tools、products、architecture、usage、README、开发与检查导航。本次提交实现、说明与验收证据；未推送、切换正式入口或部署。
