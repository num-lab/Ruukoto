# 个人通用工具、资料授权与产物

Status: ready-for-agent

## 目标与边界

补齐文件读取/修改、授权范围外读取、HTTP、Web Search 和产物读取/导出。完成通用三模式及自动审查的实际行为，不能把现有服务审批和模式字段当作完整权限迁移。覆盖 A5/A6/A7/A8/A9；不引入编码工作区、旧项目或旧工具状态机。

本单承接[已确认规格](../spec.md)；当前基线、共同实施规则与验收分工见[剩余工作评估](../remaining-work.md)。本次只建单，工程与产品验收尚未开始。

## 方案

- 对照旧个人能力及 `tool-availability.ts`、`tool-router.ts`、`review.ts`、`web-search.ts`、`artifacts.ts` 建逐项实现映射，复用独立执行/校验部分；沿 25/26 接文件与命令实际权限，不以一条 unrestricted bash 代替已承诺的受控资料入口。
- 在请求确认/自动审查中保持同一受限环境，越界读取及无凭据 HTTP 读取按原规则审查，审查调用无工具且失败转拥有者；写与敏感操作按明确授权执行。完全访问免逐次审批但继续来源核实、回执和未知暂停。配置变更、撤销和审批消费均在实际执行前复核。
- 产物在截断前保存有界完整原文/字节和来源，读取分页、损坏/缺失、partial 与恢复身份明确；能引用既有命令双流或 MCP 原响应时不再复制同一正文。新引用由 durable 持有，不为 ArtifactStore 引入旧 core Db。
- 把新工具接入适用的主/子身份与未来定时来源；定义调用门与模型可见集合的同一来源，记录所有提示/权限变更。同步 personal-durable、agent-tools、execution、usage 及新窄测试。

## 验收与证据

- 三模式分别验证允许范围内成功、越界读/写/网络拒绝或审批、自动审查批准/拒绝/失败转人工、批准后参数/权限变化拒绝；真实 Linux 执行证明隔离仍有效。
- 外调/写入后强杀不重复写；未知命令、服务、MCP 与新工具相互不能绕过原工作暂停；取消后停止未核实不释放资源。
- 长文本、二进制、非零退出、部分输出、越权引用和证据损坏可核实；分页不丢原字节，秘密不进诊断或模型证据。
- 新增工具的请求、结果及自动审查输入可重建；相关旧工具/审批、Web Search、产物与 Coding 调用方回归通过。

工程验收：待验证。产品验收：按上述实际操作或真实环境要求待验收；纯内部改动不适用时说明原因，不豁免真实环境证据。
