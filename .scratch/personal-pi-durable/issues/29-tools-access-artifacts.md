# 个人通用工具、资料授权与产物

Status: ready-for-human

## 目标与边界

补齐文件读取/修改、授权范围外读取、HTTP、Web Search 和产物读取/导出。完成通用三模式及自动审查的实际行为，不能把现有服务审批和模式字段当作完整权限迁移。覆盖 A5/A6/A7/A8/A9；不引入编码工作区、旧项目或旧工具状态机。

本单承接[已确认规格](../spec.md)；当前基线、共同实施规则与验收分工见[剩余工作评估](../remaining-work.md)。拥有者指示接手后，从干净基点 `93eac52` 实施；2026-10-18 工程验收及独立终审通过，真实模型/IM与操作者体验保持待验。

## 方案

- 对照旧个人能力及 `tool-availability.ts`、`tool-router.ts`、`review.ts`、`web-search.ts`、`artifacts.ts` 建逐项实现映射，复用独立执行/校验部分；沿 25/26 接文件与命令实际权限，不以一条 unrestricted bash 代替已承诺的受控资料入口。
- 在请求确认/自动审查中保持同一受限环境，越界读取及无凭据 HTTP 读取按原规则审查，审查调用无工具且失败转拥有者；写与敏感操作按明确授权执行。完全访问免逐次审批但继续来源核实、回执和未知暂停。配置变更、撤销和审批消费均在实际执行前复核。
- 产物在截断前保存有界完整原文/字节和来源，读取分页、损坏/缺失、partial 与恢复身份明确；能引用既有命令双流或 MCP 原响应时不再复制同一正文。新引用由 durable 持有，不为 ArtifactStore 引入旧 core Db。
- 把新工具接入适用的主/子身份与未来定时来源；定义调用门与模型可见集合的同一来源，记录所有提示/权限变更。同步 personal-durable、agent-tools、execution、usage 及新窄测试。

## 接手后的细化

- 原生 `pi.tool` 持有接纳、来源、完整参数、固定文件身份或 DNS、审批/审查认领、执行开始与观察。恢复只要存在开始事实就不重发；写后落盘失败、取消和崩溃都保守保留原调用。私有产物文件先于 durable 引用保存，丢引用窗口不重新执行。
- 主/子共用来源核实与一份工具清单；三模式沿原工作权限，不把主会话新默认赋给旧子工作。越界文件读及无凭据、无自定义头/正文的 GET/HEAD 仅自动审查一次，无工具且输入/实际请求先保存；失败、非法输出、超限及恢复中的未完成审查均转人工。
- 文件执行前再核实逐段无链接路径、dev/ino、原文指纹及实际授权范围。HTTP 固定完整 URL/方法/头/正文、DNS 与凭据引用；拒绝 URL 用户信息与自带秘密头，不跟随重定向。缺凭据不降级，响应回显秘密不落证据。
- 资料范围由可信本机入口明确添加或撤销；版本变化使待消费批准失效。产物保留有界原字节、完整性与来源，主可读本实例，子只读本子会话且复核原生调用身份；命令/MCP 沿原结果引用不重复保存正文。
- 未知效果并入原来源/委托暂停、工作收尾与报告等待。HTTP 本地连接关闭不证明远端写请求结束，效果与结束分别保存核实；完全访问也遵守。未来定时来源必须接显式来源适配，当前未实现调度时不冒用主输入。
- 独立细化审查 `search_transport` 已直接核对规格、旧检索与当前源码，指出上述路径替换、safe 重放、HTTP 精确批准与子产物归属四项必要契约；已纳入实施要求，无其余方案阻断。既有确认范围不变。
