# 个人记忆、技能与新会话资料检索

Status: planning

## 目标与边界

交付新实例长期记忆、技能目录/按需加载、历史检索及模型上下文注入。覆盖 A7/A8/A11；不导入旧记忆/JSONL，不接旧项目 Db，不建设跨产品同步或新的检索平台。

本单承接[已确认规格](../spec.md)；当前基线、共同实施规则与验收分工见[剩余工作评估](../remaining-work.md)。本次只建单，工程与产品验收尚未开始。

## 方案

- 记忆以 durable documents/entries 保存稳定身份、版本、来源和撤销；复用已有校验规则，检索先使用有界简单实现。来源只指向可核实的新会话、产物或拥有者记录。
- 复用 `packages/agent/src/skills.ts` 的独立读取/解析部分；配置目录、内容版本、实际加载和动态提示持久化，技能只提供参考，不增加工具、资料或操作权限。
- 提供新主/子/定时会话适用的历史查找、原文读取与记忆接口，明确来源可见性；长期子 Agent 复用不得隐式读取父聊天或取得旧工作授权。已有个人角色配置的提示/技能需求纳入能力核对，不搬回编码角色流程。
- 采用 durable 原生压缩和已实现请求记录边界，注入前核实来源与版本；同步 personal-durable、agent-context、usage/CONTEXT 的新旧适用范围。

- 依赖：[29 通用工具与产物](29-tools-access-artifacts.md)的来源引用和访问规则；与 32 对齐定时来源，不以等待调度完整实现阻止本单开发。
- 当前角色：方案交接；范围、依赖与验收已通过独立方案审查，记录见剩余工作评估。等待上述前置，下一角色在前置满足后接手；可先做不依赖前置接口的设计。接手须核对当前 HEAD 与本单基线之间的实际变化。
- 本单的实现、独立实现审查与适用产品体验均待执行；用户此次指令仅要求重新评估并建立剩余工单。

[32 定时工作](32-scheduled-work.md)已持有真实独立定时输入、创建范围快照与公共 `personalSource`/`personalSourceSubmission` 核实入口；本单新增模型可见输入仍需自己的可重建记录、可见性与恢复证明，接入后与32/39组合验收，不据当前接口存在记作通过。

## 验收与证据

- 写入/修订版本冲突、撤销、来源缺失或越权、重启与子身份复用均有窄用例；撤销从后续查询/注入生效。
- 技能目录/文件变化、显式加载、缺文件与不可信内容不会扩大权限；实际工具和提示与持久记录逐项一致。
- 压缩前后历史可查，记忆/技能/资料引用可从记录还原；强制证据落盘失败时 provider 请求计数为零。
- 真实模型完成记忆保存后重启引用与一次技能驱动任务；不以离线请求快照代替产品效果验收。

工程验收：待验证。产品验收：按上述实际操作或真实环境要求待验收；纯内部改动不适用时说明原因，不豁免真实环境证据。
