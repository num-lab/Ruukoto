# 完整迁移验收与发布候选

Status: planning

## 目标与边界

在同一个候选版本上关闭规格 A1–A12，汇总所有能力、真实环境和独立审查证据，形成可切换制品。A12 在本单完成隔离演练，实际接管留 40；不把累计测试数或过去不同快照的通过拼成当前版本全通过。

本单承接[已确认规格](../spec.md)；当前基线、共同实施规则与验收分工见[剩余工作评估](../remaining-work.md)。本次只建单，工程与产品验收尚未开始。

## 方案

- 建立 A1–A12 到实现、测试、源码版本、环境和结果的一一映射；沿用仍有效的旧证据，对组合变化、共享依赖与新增来源重验必要部分。
- 执行真实 QQ/TG 共用主会话、图片、后台/定时、记忆/应用数据、技能/MCP、浏览器/通用工具、三模式、授权撤销与效果未知恢复的组合流程；凭据/环境缺失明确记待验。
- 复核模型输入重建、缺扩展/版本/存储故障、双进程、跨工具暂停和完整取消收尾；完成 Coding 最终回归、实际制品和规定平台/Node 范围验证。
- 在专用档案演练旧进程/独立 scope 停止、冻结归档、新接管边界、旧积压不执行和空白档案代码回退；独立实现/证据审查后给拥有者产品验收清单。

## 进展与交接

- 依赖：28–38 的适用工程与产品验收完成；真实环境缺项仍是本单阻断，不因其他工单状态关闭而跳过。
