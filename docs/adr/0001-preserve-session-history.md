# 完整保留会话历史，单独组装模型上下文

为了让拥有者能够实验上下文组装与记忆机制，项目将全部历史消息持久化，并允许 Agent 查阅。初始方案不采用有损摘要来压缩历史；某次模型调用所使用的上下文与持久化的会话历史分别管理。初始选取规则保留系统与项目指令、当前任务要求，以及预算内最近的完整交互；更早消息通过索引和历史查询工具按需读取，并为模型回答及工具结果预留空间。

这一选择保留重新查阅原文及重新组装上下文的可能性，同时带来存储、检索和上下文选择的成本。完整历史可查阅不等于模型每次都能看到全部历史，也不保证模型能够主动找回所有相关信息。后续 Jev 实验先影响模型上下文选择；长期记忆清理另外实验且保留撤销能力，原始历史删除由独立的数据保留规则决定，不交给上下文筛选器。
