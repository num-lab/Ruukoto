# Plan 作为会话模式选择，任务固定采用自动审查

普通开发会话提供 Plan 选项并持续到拥有者手动更换，替代一次性 `/plan` 文本入口。会话默认模式包含 Plan，任务单独保存计划工作方式与访问模式：Plan 固定组合工具白名单、计划说明和 `auto-review`，复用 [ADR 0003](0003-enforce-explicit-access-modes.md) 的拥有者权限边界及 [ADR 0005](0005-auto-review-mode.md) 的独立审查策略，不增加第四种访问策略。

新任务在提交时固定选择，会话设置只影响后续新任务；继续中断任务按当前默认值或显式选择创建新任务，不从输入或继续链推断 Plan。任务内部不能进入、退出 Plan 或改动其审批策略，以保证执行环境、工具集合与计划说明始终一致；需要执行时先中断、手动切换模式再继续。旧文本保留原文，通用 schema 升级不回填计划状态。保留 `bash` 等调研工具的代价是只读行为仍依赖计划说明，不能把 Plan 宣称为全面只读的安全边界。
