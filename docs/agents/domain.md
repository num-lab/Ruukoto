# 领域文档

本仓库采用 single-context 布局：

- 根目录 `CONTEXT.md`：领域术语表。
- `docs/adr/`：架构决策记录。

## 探索前读取

探索代码库前，读取 `CONTEXT.md` 和与当前工作相关的 ADR。

文件不存在时，静默继续。由 `domain-modeling` 在术语确定或需要记录决策时按需创建。

## 沿用领域术语

任务标题、方案、假设和测试名称中的领域概念，应采用 `CONTEXT.md` 定义的术语。

需要的概念尚未收录时，先判断是否应使用已有术语；确有缺口时，交由 `domain-modeling` 补充。

## 明确指出决策冲突

方案与已有 ADR 冲突时，明确标出相关 ADR，并说明重新讨论该决策的理由。
