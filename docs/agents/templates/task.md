# 工单标题

Status: planning

## 目标与边界

写目标、非目标、关键契约、验收要求及拥有者确认的来源；已有共享规格时引用具体段落。待决定的取舍与已确认内容分开。简单任务按轻量路径记录，不强制填写完整模板。

## 方案

写当前可执行步骤、受影响的调用方与文件、文档落点和验证方法。理由与被否方案链接到决策笔记，不在这里重复。

## 进展与交接

- 当前角色与阶段：记录已完成什么，不用历史评论拼接现状。
- 下一角色与动作：给出可以直接执行的下一步。
- 当前内容：记录分支、基点与 HEAD；有未提交或未跟踪内容时列出本任务范围，并提供可核对的 diff 或快照引用。HEAD 不能代表未提交的改动。
- 阻塞与恢复条件：缺什么、由谁补齐；没有则写无。

## 验收与证据

每项要求记录检查方法、实际环境与结果、证据位置及未覆盖项。区分模拟、真实执行与未执行；来源是作者记录还是审查者亲验也要写明。

工程验收记录待验证／未通过／通过；产品验收记录待验收／未通过／通过／不适用及理由。需要人工时写清待验事项；必要真实环境证据不能省略为不适用。

方案与实现审查分别记录审查者角色、日期、被审内容、结论和阻断项。已提交内容记录提交号；未提交内容引用被审 diff 或快照，包含未跟踪文件。记录后发生实质改动，标明哪些旧结论失效，并补充受影响部分的复审结果。

## Comments

按日期追加讨论与审查过程。已确认的新要求、当前进展和最终结论同时更新正文；历史评论保持来源，不覆盖现行记录。
