# Triage 状态

普通工单顶部的 `Status:` 使用下表，角色与实际标签同名；推进条件见[开发流程](../../.agents/skills/development-workflow/SKILL.md)。

| 标签 | 含义 |
| --- | --- |
| needs-triage | 待评估 |
| needs-info | 缺信息或待拥有者决定 |
| planning | 编写或修订方案 |
| plan-review | 待独立方案审查 |
| ready-for-agent | 范围已确认，可实施；重流程方案已过审 |
| in-progress | 实施与文档同步 |
| in-review | 待独立实现审查 |
| ready-for-human | 待人工实现、体验或环境验收 |
| resolved | 工程及适用的产品验收通过 |
| wontfix | 决定不处理 |
