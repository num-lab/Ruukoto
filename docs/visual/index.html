怎样维护

  1. 改了 src/ 或 deploy/ 下的文件后，找出描述它的页面：grep -l <文件路径> docs/visual/*.html。
  2. 按改动更新图、表和正文。只用 style.css 注释里列出的组件和语义色，图用手写内联 SVG，不引外部资源。
  3. 跑 npm test（或只跑 test/67-visual-docs.test.ts）。它核对源码锚点仍然存在、页面覆盖了代码里的状态、表、op 与事件，并要求新页面被本页链接。

检查只能发现「代码结构变了而页面没跟上」，发现不了「页面说错了」。语义上的变化要靠改代码的人顺手更新。直接用浏览器打开本文件即可阅读，不需要服务器。

维护规则写在 AGENTS.md「可视化文档」一节。
